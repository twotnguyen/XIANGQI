# TRẠNG THÁI CỤ THỂ TỪNG MÀN HÌNH

**Cập nhật:** 2026-09-22 · **Căn cứ:** DEC-048. Đây là đặc tả hành vi UI, chưa phải ảnh chụp hoặc kết quả kiểm thử.

Mỗi hàng dùng ID từ [screen-inventory](screen-inventory.md); quyền và thời hạn lấy từ requirement tương ứng, không tạo bộ luật thứ hai. “Không áp dụng” phải có lý do. Lỗi không được tiết lộ dữ liệu vượt quyền; giao diện chỉ phản ánh kết quả máy chủ.
