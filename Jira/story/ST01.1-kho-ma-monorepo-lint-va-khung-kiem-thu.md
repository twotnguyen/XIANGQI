**Câu chuyện:** Là thành viên nhóm phát triển, tôi muốn một kho mã có sẵn cấu trúc, lệnh build/lint/test thống nhất, để mọi người code cùng quy ước và mọi thay đổi đều được kiểm tự động.

**Tiêu chí chấp nhận:**
1. *Given* máy mới đã cài Node 24 và pnpm đúng phiên bản ghi trong README, *When* chạy `pnpm install --frozen-lockfile`, `pnpm build`, `pnpm typecheck`, `pnpm lint`, *Then* cả bốn lệnh exit 0 và có thư mục `dist/` ở cả 6 package.
2. *Given* server đã build, *When* gọi `GET /health`, *Then* nhận `200` với body JSON `{"ok":true}`.
3. *Given* file trong `packages/game-rules` import `pg`, *When* chạy `pnpm lint`, *Then* lint báo lỗi luật `no-restricted-imports`.
4. *Given* truyền đường dẫn test không tồn tại, *When* chạy `pnpm test:unit -- <đường-dẫn-sai>` hoặc `pnpm test:e2e -- <đường-dẫn-sai>`, *Then* lệnh exit khác 0.
5. Đồng hồ giả `createTestClock` có đủ 5 hàm và chạy đúng hẹn giờ; Playwright tạo được 8 phiên trình duyệt không dùng chung storage.
