**Câu chuyện:** Là trưởng nhóm, tôi muốn mọi PR tự động chạy 4 cổng kiểm tra và không thể merge khi đỏ; là lập trình viên backend, tôi muốn chạy Supabase ở máy mình để test trên PostgreSQL thật.

**Tiêu chí chấp nhận:**
1. PR sạch → CI xanh, chạy đủ `lint → typecheck → build → test:unit` + e2e smoke.
2. PR có lỗi lint / lỗi kiểu / test đỏ / test `.skip` / `.only` → CI **đỏ** tương ứng (chứng minh bằng 5 PR thử thật).
3. Nhánh `main` bật bảo vệ: bắt buộc CI xanh mới merge.
4. `supabase start` chạy; cổng API 54321, DB 54322, Studio 54323, hộp thư 54324 phản hồi; xác minh email **bật**.
5. Server thiếu biến bắt buộc → dừng ngay, thông báo rõ tên biến, **không in giá trị bí mật**.
6. `pnpm test:integration` kết nối PostgreSQL thật; tắt DB thì **thất bại** (không skip).
