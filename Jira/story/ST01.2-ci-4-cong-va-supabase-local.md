## 1. CÂU CHUYỆN NGƯỜI DÙNG

> **Là** trưởng nhóm, **tôi muốn** mọi PR tự động chạy 4 cổng kiểm tra và **không thể merge khi đỏ**;
> **là** lập trình viên backend, **tôi muốn** chạy Supabase ở máy mình,
> **để** code lỗi không lọt vào `main` và mọi test dữ liệu chạy trên PostgreSQL thật.

## 2. BỐI CẢNH

- `AGENTS.md` §5: từ ISSUE-003 trở đi, 4 cổng `lint → typecheck → build → test:unit` phải exit 0 trước khi mở PR. CI là nơi **ép** luật này.
- Luật tuyệt đối số 6: test dữ liệu chạy trên **PostgreSQL thật**; thiếu DB ⇒ test **đỏ**, không được bỏ qua.
- Khoá bí mật (Supabase secret, HMAC, LiveKit) **không** được vào Git, log hay gói JavaScript của web (mọi biến `VITE_*` là công khai).

## 3. PHẠM VI

**✅ Làm:** GitHub Actions (quality, e2e, integration), chặn `.skip`/`.only`, bảo vệ nhánh `main`, Supabase local + xác minh email, `.env.example`, lane integration tối thiểu, module `env.ts` kiểm cấu hình server.
**❌ Không làm:** bảng dữ liệu (EP05), harness tích hợp đầy đủ (TK05.3.1), triển khai Internet (EP16).
