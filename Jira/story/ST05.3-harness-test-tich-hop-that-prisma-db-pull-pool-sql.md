> **Là** lập trình viên backend và tester,
> **tôi cần** công cụ dựng dữ liệu/người dùng thật, rào đồng bộ cho test tranh chấp, và lớp truy cập dữ liệu (Prisma để đọc, `pg` + transaction cho SQL thuần),
