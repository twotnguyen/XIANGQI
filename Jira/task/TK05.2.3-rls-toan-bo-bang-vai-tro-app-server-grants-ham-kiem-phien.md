**Việc cần làm:** `<ts>_rls.sql`
1. `ALTER TABLE public.<bảng> ENABLE ROW LEVEL SECURITY;` cho **mọi** bảng ứng dụng (profiles, friendships, rooms, room_members, room_blocks, user_active_room, invitations, matches, match_moves, match_events, active_players, command_receipts, match_proposals, room_rematch_votes, room_command_receipts, room_side_swap_proposals, chat_* (4), media_* (3), ai_jobs, client_controls, app_sessions, auth_security_jobs).
2. **Không tạo policy nào cho `anon` và `authenticated`** ⇒ trình duyệt không đọc/ghi thẳng bảng; mọi dữ liệu qua máy chủ. `REVOKE ALL ON ALL TABLES IN SCHEMA public FROM anon, authenticated;`
3. `CREATE ROLE app_server LOGIN PASSWORD '<từ biến môi trường khi seed local>' NOBYPASSRLS NOSUPERUSER;` `GRANT USAGE ON SCHEMA public`, `GRANT SELECT, INSERT, UPDATE, DELETE ON ALL TABLES IN SCHEMA public TO app_server`, `GRANT USAGE, SELECT ON ALL SEQUENCES`; mỗi bảng tạo policy `FOR ALL TO app_server USING (true) WITH CHECK (true)`. ⛔ **Không** `BYPASSRLS`, **không** SUPERUSER, **không** cấp SELECT `auth.users`/`auth.sessions`.
4. Schema `private` (không expose qua API):
   - `private.is_auth_session_active(session_id uuid, user_id uuid) RETURNS boolean SECURITY DEFINER SET search_path = ''`.
   - `private.get_auth_session_metadata(session_id uuid, user_id uuid) RETURNS TABLE(created_at timestamptz) SECURITY DEFINER SET search_path = ''` — chỉ trả `created_at` khi cặp khớp và phiên còn hiệu lực; sai/hết hạn trả rỗng; không trả email/token.
   - Viết đầy đủ tên bảng (`auth.sessions`), không dynamic SQL; `REVOKE ALL ON FUNCTION ... FROM PUBLIC, anon, authenticated`; `GRANT EXECUTE ... TO app_server`; `GRANT USAGE ON SCHEMA private TO app_server`.
5. Cập nhật `.env.example`: `DATABASE_URL` của server dùng user `app_server`; thêm `DATABASE_ADMIN_URL` (chỉ dùng cho seed/test, không dùng trong app).
6. Test `tests/integration/issue-043.test.ts` (11 ca ở TK05.2.3), kết nối bằng **từng role thật** (anon/authenticated qua PostgREST bằng khoá publishable + JWT, `app_server` qua `pg`).

**Bẫy dễ gặp:** chỉ thử khoá anon (authenticated có quyền khác); chạy test bằng superuser che hết lỗi.
