### 5.1 Cài

### 5.2 `vitest.config.ts`
```ts
import { defineConfig } from 'vitest/config';
export default defineConfig({
  test: {
    include: ['tests/unit/**/*.test.ts', 'packages/**/src/**/*.test.ts', 'apps/**/src/**/*.test.ts'],
    exclude: ['**/node_modules/**', '**/dist/**', 'tests/integration/**', 'tests/e2e/**', 'tests/media/**', 'tests/load/**', 'tests/ai/**'],

  },

```
Script `test:unit` = `vitest run --config vitest.config.ts` (không ghi cứng thư mục ⇒ tham số sau `--` được chuyển tiếp nguyên vẹn).

### 5.3 `tests/fixtures/test-clock.ts` — đúng giao diện này
```ts
export interface TestClock {
  now(): number;                                 // mốc hiện tại (ms)
  set(ms: number): void;                         // đặt mốc khi chuẩn bị test
  advance(ms: number): void;                     // CHỈ tăng now, KHÔNG tự chạy hẹn giờ
  runDueTasks(): void;                           // chạy mọi hẹn giờ có atMs <= now
  schedule(atMs: number, fn: () => void): void;  // đăng ký hẹn giờ
}
export function createTestClock(startMs = 0): TestClock { /* … */ }
```
Quy tắc bắt buộc của `runDueTasks()`:
1. Chạy các việc có `atMs <= now()` theo **`atMs` tăng dần**; cùng `atMs` thì theo **thứ tự đăng ký**.
2. Nếu một việc đang chạy lại `schedule` thêm việc **đã tới hạn** ⇒ chạy luôn trong cùng lần gọi.
3. Mỗi việc chỉ chạy **một lần** (gọi `runDueTasks()` lần 2 không chạy lại).
4. **Không** giả `Date.now` toàn cục.

Gợi ý cài đặt: mảng `{ atMs, seq, fn, done }`; trong vòng `while` tìm việc chưa chạy nhỏ nhất theo `(atMs, seq)` mà `atMs <= now`, chạy, đánh dấu `done`, lặp tới khi hết.

### 5.4 `tests/unit/smoke.test.ts`
Tên test có ID:
```ts
import { describe, it, expect } from 'vitest';
import { createTestClock } from '../fixtures/test-clock';

describe('TestClock', () => {
  it('[T003-03] advance(1000) làm now() tăng đúng 1000', () => {
    const c = createTestClock(0); c.advance(1000); expect(c.now()).toBe(1000);
  });
  it('[T003-04] hẹn ở 500 chỉ chạy khi now >= 500 và chỉ 1 lần', () => {
    const c = createTestClock(0); let n = 0; c.schedule(500, () => n++);
    c.advance(400); c.runDueTasks(); expect(n).toBe(0);

  it('[T003-06] việc đăng ký trong lúc chạy mà đã tới hạn thì chạy luôn', () => { /* … */ });
});
```

### 5.5 README — mục "Viết test có thời gian"
3 dòng: luôn nhận `clock` qua tham số/constructor; không gọi `Date.now()` trong mã nghiệp vụ; test dùng `createTestClock` + `advance` + `runDueTasks`.

### B. Các ca kiểm thử

#### QA01.1.3-01 · Lane unit chạy thật
- **Các bước:** `pnpm test:unit; echo "exit=$?"`
- **Mong đợi:** dòng tổng kết dạng `Tests  4 passed (4)` (≥ 4), không có `skipped`; `exit=0`.

#### QA01.1.3-02 · Sai tên file ⇒ đỏ ⭐
- **Các bước:** `pnpm test:unit -- tests/unit/khong-ton-tai.test.ts; echo "exit=$?"`
- **Mong đợi:** thông báo kiểu `No test files found`; `exit` **khác 0**.

#### QA01.1.3-03 · Chọn đúng một file
- **Các bước:** `pnpm test:unit -- tests/unit/smoke.test.ts`
- **Mong đợi:** dòng `Test Files  1 passed (1)`.

#### QA01.1.3-04 · Lane unit không chạy nhầm test tích hợp
- **Các bước:** tạo file tạm `tests/integration/probe.test.ts` với nội dung:
  ```ts
  import { it } from 'vitest'; it('không được chạy', () => { throw new Error('lane unit chạy nhầm'); });
  ```
  → `pnpm test:unit; echo "exit=$?"` → `rm tests/integration/probe.test.ts`
- **Mong đợi:** `exit=0`; output **không** nhắc `probe.test.ts`.

#### QA01.1.3-05 · Đồng hồ giả đủ 5 hàm
- **Các bước:** mở `tests/fixtures/test-clock.ts`.
- **Mong đợi:** có đủ `now`, `set`, `advance`, `runDueTasks`, `schedule`; trong `advance` **không** gọi `runDueTasks`; không có `Date.now`.

#### QA01.1.3-06 · Đúng mốc là chạy, chỉ chạy 1 lần ⭐
- **Các bước:** tạo file tạm `tests/unit/qa-clock.test.ts`:
  ```ts
  import { it, expect } from 'vitest';
  import { createTestClock } from '../fixtures/test-clock';
  it('QA đúng mốc', () => {
    const c = createTestClock(0); let n = 0; c.schedule(500, () => n++);
    c.advance(499); c.runDueTasks(); expect(n).toBe(0);
    c.advance(1);   c.runDueTasks(); expect(n).toBe(1);
    c.runDueTasks(); expect(n).toBe(1);
  });
  it('QA thứ tự', () => {
    const c = createTestClock(0); const out: string[] = [];
    c.schedule(600, () => out.push('C')); c.schedule(500, () => out.push('A')); c.schedule(500, () => out.push('B'));
    c.advance(1000); c.runDueTasks(); expect(out).toEqual(['A', 'B', 'C']);
  });
  ```
  → `pnpm test:unit -- tests/unit/qa-clock.test.ts` → `rm tests/unit/qa-clock.test.ts`
- **Mong đợi:** `2 passed`.

#### QA01.1.3-07 · Thử phá: test bắt được lỗi ⭐
- **Các bước:** trong `test-clock.ts` đổi điều kiện `<=` thành `<` → `pnpm test:unit` → `git checkout tests/fixtures/test-clock.ts`
- **Mong đợi:** `T003-04` **đỏ**. Sau khi hoàn lại, chạy lại xanh.

- **Mong đợi:** `passWithNoTests: false`.
