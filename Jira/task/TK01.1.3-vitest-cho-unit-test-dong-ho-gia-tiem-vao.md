**Mục tiêu:** Bộ chạy unit test **thất bại rõ ràng** khi chọn sai đường dẫn, và có sẵn **đồng hồ giả** để mọi test thời gian (đồng hồ ván, treo ván, hết hạn lời mời…) không phải chờ thật.

**Việc cần làm:**
1. `vitest.config.ts`: `include` **chỉ** `tests/unit/**/*.test.ts` và `packages/**/src/**/*.test.ts`; `exclude` rõ `tests/integration/**`, `tests/e2e/**`, `tests/media/**`, `tests/load/**`, `tests/ai/**`; **`passWithNoTests: false`**; bật coverage reporter `text` nhưng **không đặt ngưỡng**.
2. `tests/fixtures/test-clock.ts` đúng giao diện:
   ```ts
   export interface TestClock {
     now(): number;                                // mốc hiện tại (ms)
     set(ms: number): void;                        // đặt mốc khi setup
     advance(ms: number): void;                    // chỉ tăng now, KHÔNG tự chạy hẹn giờ
     runDueTasks(): void;                          // chạy mọi hẹn giờ có atMs <= now
     schedule(atMs: number, fn: () => void): void; // đăng ký hẹn giờ
   }
   export function createTestClock(startMs?: number): TestClock;
   ```
   Quy tắc: `runDueTasks` chạy theo `atMs` tăng dần, cùng mốc thì theo thứ tự đăng ký; nếu callback đăng ký thêm task đã tới hạn thì chạy luôn trong lần gọi đó; mỗi task chỉ chạy **một lần**. **Không** giả `Date.now` toàn cục.
3. `tests/unit/smoke.test.ts` gồm các test có ID trong tên:
   - `T003-03` `advance(1000)` làm `now()` tăng đúng 1000.
   - `T003-04` hẹn ở 500: `advance(400); runDueTasks()` → chưa chạy; `advance(100); runDueTasks(); runDueTasks()` → chạy đúng 1 lần tại 500.
   - Hai task cùng mốc 500 chạy đúng thứ tự đăng ký.
4. Script `test:unit` = `vitest run --config vitest.config.ts` và **chuyển tiếp** tham số sau `--`.
5. Thêm vào README mục "Viết test có thời gian": luôn nhận `clock` qua tham số/constructor, không gọi `Date.now()` trực tiếp trong mã nghiệp vụ.

**File/module:** `vitest.config.ts`, `tests/fixtures/test-clock.ts`, `tests/unit/smoke.test.ts`, `package.json`.

**Không làm:** runner integration (TK01.2.2), Playwright (TK01.1.4).

**Bẫy dễ gặp:** `passWithNoTests: true` (mặc định ở một số cấu hình) → chọn sai file vẫn xanh. Điều kiện tới hạn phải là `<=` (đúng tại mốc 500 là chạy).

**Bàn giao:** `pnpm test:unit` thật; `createTestClock` cho các Task EP03, EP04, EP11.

**Tự kiểm:** `pnpm test:unit` exit 0; `pnpm test:unit -- tests/unit/khong-ton-tai.test.ts` exit ≠ 0; đổi `<=` thành `<` trong clock thì `T003-04` phải đỏ (rồi hoàn lại).
