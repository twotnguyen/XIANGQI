**Việc cần làm:**
1. `packages/contracts/src/match.ts`:
   ```ts
   export type MatchMode = 'ONLINE' | 'AI';
   export type MatchStatus = 'ACTIVE' | 'FINISHED' | 'INTERRUPTED';
   export type TimeControl = 0 | 300 | 600 | 900;   // giây mỗi bên; 0 = không giới hạn
   export type AiLevel = 'EASY' | 'MEDIUM' | 'HARD';
   export type OutcomeReason = 'CHECKMATE' | 'STALEMATE' | 'REPETITION' | 'AGREED_DRAW'
     | 'RESIGN' | 'TIMEOUT' | 'INACTIVITY' | 'DISCONNECT'
     | 'BOTH_OFFLINE' | 'SERVER_RESTART' | 'AI_UNAVAILABLE';
   export type Outcome = { winner: Side | null; reason: OutcomeReason };
   export type ClockState = { redMs: number; blackMs: number; runningSinceEpochMs: number } | null;
   export type ProposalKind = 'DRAW' | 'UNDO';
   export type Proposal = { id: string; kind: ProposalKind; requesterId: string; basePly: number; createdVersion: number; expiresAtMs: number };
   export type InactivityPhase = 'NORMAL' | 'PROMPTING' | 'COUNTDOWN';
   export type InactivityState = { phase: InactivityPhase; extensionsUsed: number /* 0..2 */; deadlineMs: number | null } | null;
   export type PresenceEntry = { userId: string; online: boolean; disconnectDeadlineMs: number | null };
   export type MatchSnapshot = { id: string; roomId: string | null; mode: MatchMode; status: MatchStatus;
     position: Position; version: number /* chỉ tăng */; ply: number /* có thể giảm khi đi lại */;
     ruleSetVersion: string; redUserId: string | null; blackUserId: string | null;
     aiSide: Side | null; aiLevel: AiLevel | null; timeControl: TimeControl; clock: ClockState;
     outcome: Outcome | null; activeMoveIds: string[]; proposal: Proposal | null;
     inactivity: InactivityState; presence: PresenceEntry[]; aiState: AiState; serverNowMs: number };
   ```
   Thêm hàm `winnerOf(reason, loserSide)` hoặc bảng ánh xạ: `REPETITION`, `AGREED_DRAW`, `BOTH_OFFLINE`, `SERVER_RESTART`, `AI_UNAVAILABLE` ⇒ `winner = null`; 3 lý do cuối là **gián đoạn** (không ai thua).
2. `packages/contracts/src/room.ts`:
   ```ts
   export type MemberRole = 'PLAYER' | 'SPECTATOR';   // VAI TRÒ trong phòng
   export type GrantRole = 'PLAY' | 'WATCH';          // LOẠI QUYỀN của lời mời/mã/link
   export type Visibility = 'PUBLIC' | 'CODE_ONLY' | 'LOCKED';
   export type RoomStatus = 'WAITING' | 'PLAYING' | 'FINISHED' | 'CLOSED';
   export const MAX_PLAYERS = 2; export const MAX_SPECTATORS = 5; export const MAX_MEMBERS = 7;
   ```
   Thành viên `{ userId, membershipId, role, side: Side | null /* chỉ khác null khi PLAYER */, online, ready, readyRevision, readyConfigRevision }`. Phòng `{ id, name, ownerId, visibility, status, roomVersion, configRevision, timeControl, members, currentMatchId, currentChatContextId, spectatorCount }`. Lời mời `{ id, kind: 'DIRECT'|'CODE'|'LINK', grantRole, roomId, recipientId /* chỉ khác null khi DIRECT */, expiresAtMs, consumed }`. **Không** có trường mã/token trong kiểu gửi client. Dùng *branded type* hoặc literal khác nhau để `MemberRole` và `GrantRole` gán chéo lỗi biên dịch.
3. `chat.ts`: `ChatChannel = 'PLAYERS' | 'ROOM'` (PLAYERS = kênh riêng 2 người chơi; ROOM = kênh chung: 5 người xem + cả 2 người chơi), `ChatMessage { id, contextId, channel, privateSegmentId: string|null, sequence, sender:{id, displayName}, senderIsPlayer, content, createdAtMs, clientMessageId }`, `CHAT_MAX_LENGTH = 1000`, `CHAT_RATE_LIMIT = { messages: 5, perMs: 10_000 }`, `CHAT_PAGE_SIZE = 50`.
4. `media.ts`: `MediaKind = 'CAMERA'|'MICROPHONE'`, `Audience = 'OFF'|'OPPONENT_ONLY'|'OPPONENT_AND_SPECTATORS'`, `SourcePolicy { camera: Audience; microphone: Audience }`, `PolicyState { userId, policyVersion, appliedVersion, desired, applied, status: 'APPLYING'|'APPLIED'|'FAILED' }`. Không có trường `token`.
5. `ai.ts`: `AiJobState = 'IDLE'|'QUEUED'|'THINKING'|'FAILED'`, `AiState = { jobId: string|null; jobVersion: number; state: AiJobState } | null`, `AI_LEVELS = { EASY:{depthCap:2,budgetMs:300}, MEDIUM:{depthCap:4,budgetMs:1000}, HARD:{depthCap:6,budgetMs:3000} } as const`, `AI_MAX_RUNNING = 2`, `AI_MAX_QUEUED = 8`, `SearchResult { move: Move|null; score; nodes; completedDepth; elapsedMs; pv: Move[]; aborted }`.
6. `errors.ts` — `ErrorCode` đủ: `UNAUTHENTICATED, FORBIDDEN, VALIDATION_ERROR, NOT_FOUND, CONFLICT, RATE_LIMITED, EMAIL_UNVERIFIED, ONBOARDING_REQUIRED, ROOM_FULL, ROOM_CLOSED, ALREADY_IN_ROOM, INVITE_INVALID, BLOCKED_FROM_ROOM, NOT_YOUR_TURN, INVALID_MOVE, VERSION_CONFLICT, COMMAND_ID_REUSED, MATCH_ENDED, PROPOSAL_EXPIRED, AI_BUSY, MEDIA_UNAVAILABLE, ROOM_ACCESS_UNAVAILABLE, ACCESS_DENIED, ROOM_NOT_WAITING, STALE_ROOM_CONFIG, STALE_READY, MESSAGE_ID_REUSED, PROPOSAL_PENDING`.
7. `api.ts` — `ApiResult<T> = { ok: true; data: T; requestId: string } | { ok: false; error: { code: ErrorCode; message: string }; requestId: string }`.
8. `schemas.ts` — **mọi schema input có `.strict()`**:
   | Schema | Ràng buộc |
   |---|---|
   | `SquareSchema` | x số nguyên 0..8, y số nguyên 0..9 |
   | `MoveSchema` | `{ from, to }` |
   | `MatchCommandSchema` | `commandId` UUID, `expectedVersion` số nguyên ≥ 0, `payload` |
   | `CreateRoomSchema` | `name` 1..60, `visibility` enum, `timeControl` ∈ {0,300,600,900} |
   | `JoinRoomSchema` | `commandId` UUID, `intent` PLAY/WATCH, **đúng một** trong `roomId`/`code`/`token`/`invitationId`; không nhận `role`, `side`, `userId`, `ownerId` |
   | `ReadySchema` | `commandId`, `membershipId`, `expectedConfigRevision`, `expectedReadyRevision`, `ready` (boolean) |
   | `ChatSendSchema` | `contextId` UUID, `channel` PLAYERS/ROOM, `privateSegmentId` UUID **bắt buộc khi PLAYERS, cấm khi ROOM**, `clientMessageId` UUID, `content` 1..1000; không nhận `senderId`, `role`, `senderIsPlayer`, `matchId` |
   | `MediaPolicySchema` | `camera`, `microphone` ∈ Audience, `expectedPolicyVersion` |
   | `CreateAiMatchSchema` | `level` EASY/MEDIUM/HARD, `humanSide` RED/BLACK, `timeControl` |
   | `RegisterSchema` | `username` `^[a-z0-9_]{3,24}$`, `email` hợp lệ, `password` 10..128 ký tự |
   | `LoginSchema` | `username`, `password`, `remember` boolean |
9. Unit test cho từng ràng buộc ở bảng trên và bảng ánh xạ winner.

**Không làm:** gắn schema vào route (các Epic sau).

**Bẫy dễ gặp:** thiếu `.strict()` ⇒ client gửi `{winner:'RED'}` và nếu tầng dưới trải object thì tự thắng. Đặt tên kênh là `SPECTATORS` (tên cũ) khiến lập trình viên chặn nhầm người chơi — tên đúng là `ROOM`.

**Bàn giao:** toàn bộ kiểu + schema + mã lỗi export từ `@xiangqi/contracts`; bảng tóm tắt trong comment đầu `schemas.ts`.

**Tự kiểm:** `pnpm test:unit -- packages/contracts`, `pnpm typecheck`, `pnpm lint`.
