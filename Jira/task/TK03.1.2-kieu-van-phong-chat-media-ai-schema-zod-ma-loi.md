## 1. MỤC TIÊU (đọc trong 1 phút)

Viết toàn bộ **"hợp đồng dữ liệu"** giữa web và server trong `@xiangqi/contracts`:
1. **Kiểu** cho ván, phòng, chat, camera/mic, AI.
2. **Schema Zod** kiểm mọi dữ liệu client gửi lên — **trường thừa bị từ chối** (`.strict()`).
3. **Mã lỗi** thống nhất + **bảng ánh xạ mã lỗi → HTTP**.
4. Vỏ kết quả **`ApiResult`** mọi API dùng chung.

Ba nơi (web, server, AI) import từ đây ⇒ hiểu dữ liệu giống nhau; server từ chối mọi dữ liệu giả mạo ngay cửa vào.

## 2. KHÁI NIỆM CẦN BIẾT

| Khái niệm | Giải thích |
|---|---|
| **Zod schema** | Mô tả khuôn dữ liệu và kiểm lúc chạy: `CreateRoomSchema.parse(body)` sai khuôn ⇒ ném lỗi |
| **`.strict()`** | Có trường không khai báo ⇒ từ chối. Chặn kẻ gian gửi thêm `winner: 'RED'`, `role: 'PLAYER'` |
| **`PLAYER`/`SPECTATOR` vs `PLAY`/`WATCH`** | `MemberRole` = **vai trò** trong phòng. `GrantRole` = **loại quyền** của lời mời/mã/link. Dùng mã WATCH vào phòng ⇒ **trở thành** SPECTATOR. Hai kiểu **khác nhau**, gán chéo phải **lỗi biên dịch** |
| **`ApiResult`** | `{ ok: true, data }` hoặc `{ ok: false, error: { code, message } }` — xem [Từ điển](../05-TU-DIEN-KY-THUAT.md#api-result) |
| **Không rò bí mật** | Kiểu gửi cho client **không bao giờ** có trường `code`, `token`, `secret`, `hmac` (mã phòng/link chỉ trả đúng lúc tạo, qua API riêng) |

**Từ kỹ thuật cần tra:** [Zod & .strict()](../05-TU-DIEN-KY-THUAT.md#zod) · [ApiResult](../05-TU-DIEN-KY-THUAT.md#api-result) · [API & HTTP](../05-TU-DIEN-KY-THUAT.md#api) · [version](../05-TU-DIEN-KY-THUAT.md#version) · [commandId](../05-TU-DIEN-KY-THUAT.md#idempotency)

### 5.1 `match.ts`
```ts
export type MatchMode = 'ONLINE' | 'AI';
export type MatchStatus = 'ACTIVE' | 'FINISHED' | 'INTERRUPTED';
export type TimeControl = 0 | 300 | 600 | 900;          // giây mỗi bên; 0 = không giới hạn (mặc định)
export type AiLevel = 'EASY' | 'MEDIUM' | 'HARD';
export type OutcomeReason = 'CHECKMATE' | 'STALEMATE' | 'REPETITION' | 'AGREED_DRAW'
  | 'RESIGN' | 'TIMEOUT' | 'INACTIVITY' | 'DISCONNECT'
  | 'BOTH_OFFLINE' | 'SERVER_RESTART' | 'AI_UNAVAILABLE';          // đúng 11 giá trị
export type Outcome = { winner: Side | null; reason: OutcomeReason };
export type ClockState = { redMs: number; blackMs: number; runningSinceEpochMs: number } | null;   // null = không giới hạn
export type ProposalKind = 'DRAW' | 'UNDO';
export type Proposal = { id: string; kind: ProposalKind; requesterId: string; basePly: number; createdVersion: number; expiresAtMs: number };
export type InactivityPhase = 'NORMAL' | 'PROMPTING' | 'COUNTDOWN';
export type InactivityState = { phase: InactivityPhase; extensionsUsed: number /* 0..2 */; deadlineMs: number | null } | null;
export type PresenceEntry = { userId: string; online: boolean; disconnectDeadlineMs: number | null };
export type MatchSnapshot = {
  id: string; roomId: string | null; mode: MatchMode; status: MatchStatus;
  position: Position; version: number /* chỉ tăng */; ply: number /* có thể giảm khi đi lại */;
  ruleSetVersion: string; redUserId: string | null; blackUserId: string | null;
  aiSide: Side | null; aiLevel: AiLevel | null; timeControl: TimeControl; clock: ClockState;
  outcome: Outcome | null; activeMoveIds: string[]; proposal: Proposal | null /* chỉ đề nghị ĐANG CHỜ */;
  inactivity: InactivityState; presence: PresenceEntry[]; aiState: AiState; serverNowMs: number;
};
```
Bảng người thắng theo lý do (`GR-END-05`) — viết thành hàm `winnerOf(reason, loserSide): Side | null` và `isInterrupted(reason)`:

| Lý do | Người thắng | Gián đoạn? |
|---|---|---|
| `CHECKMATE`, `STALEMATE`, `RESIGN`, `TIMEOUT`, `INACTIVITY`, `DISCONNECT` | đối thủ của `loserSide` | Không |
| `REPETITION`, `AGREED_DRAW` | `null` (hoà) | Không |
| `BOTH_OFFLINE`, `SERVER_RESTART`, `AI_UNAVAILABLE` | `null` | **Có** (không ai thua) |

### 5.2 `room.ts`
```ts
export type MemberRole = 'PLAYER' | 'SPECTATOR';   // VAI TRÒ trong phòng
export type GrantRole = 'PLAY' | 'WATCH';          // LOẠI QUYỀN của lời mời/mã/link
export type Visibility = 'PUBLIC' | 'CODE_ONLY' | 'LOCKED';
export type RoomStatus = 'WAITING' | 'PLAYING' | 'FINISHED' | 'CLOSED';
export const MAX_PLAYERS = 2; export const MAX_SPECTATORS = 5; export const MAX_MEMBERS = 7;
```
- `RoomMember { userId, membershipId, role: MemberRole, side: Side | null /* chỉ khác null khi PLAYER */, displayName, online, ready, readyRevision, readyConfigRevision }`
- `Room { id, name, ownerId, visibility, status, roomVersion, configRevision, timeControl, members, currentMatchId, currentChatContextId, spectatorCount }`
- `Invitation { id, kind: 'DIRECT' | 'CODE' | 'LINK', grantRole, roomId, roomName, inviterDisplayName, recipientId /* chỉ DIRECT */, expiresAtMs, consumed }` — **không** có mã/token.
- Để gán chéo `MemberRole` ↔ `GrantRole` lỗi biên dịch: hai tập giá trị đã khác nhau (`'PLAYER'` ≠ `'PLAY'`) nên TypeScript tự báo lỗi — viết test `@ts-expect-error` để chứng minh.
