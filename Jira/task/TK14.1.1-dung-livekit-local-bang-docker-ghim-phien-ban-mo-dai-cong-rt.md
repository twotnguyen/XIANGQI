**Việc cần làm:**
1. `infra/compose.yaml`: service `livekit` dùng image `livekit/livekit-server:<phiên bản cụ thể>` (**cấm** `latest`); cổng: `7880` (HTTP/WS), `7881/tcp` (RTC TCP), dải UDP `50000-50100` (RTC); ghi rõ trong comment.
2. `infra/livekit.yaml`: `port: 7880`, `rtc: { tcp_port: 7881, port_range_start: 50000, port_range_end: 50100, use_external_ip: false, node_ip: 127.0.0.1 }` (bật ứng viên loopback cho local), `keys:` dùng cặp khoá **chỉ cho dev/test** đọc từ biến môi trường (`LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`) — không commit khoá thật (`.env.example` để giá trị mẫu `devkey`/`devsecret-change-me`).
3. Script gốc: `media:start` (`docker compose -f infra/compose.yaml up -d livekit`), `media:stop`, `media:status`.
4. README mục "Chạy LiveKit local": yêu cầu Docker, lệnh, cổng cần mở trên firewall, cách kiểm `curl http://127.0.0.1:7880` trả OK.
5. Ghi chú: camera/mic trên điện thoại trong mạng nội bộ cần **ngữ cảnh an toàn** (HTTPS) — IP nội bộ không đủ; hướng dẫn dùng HTTPS local (ví dụ mkcert) khi kiểm thiết bị thật.

**Bẫy dễ gặp:** lần trước thiếu cấu hình dải cổng RTC (`F-28`) ⇒ kết nối "thành công" nhưng không có luồng.
