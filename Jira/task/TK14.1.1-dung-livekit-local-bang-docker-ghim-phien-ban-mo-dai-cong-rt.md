## 1. MỤC TIÊU (đọc trong 1 phút)

Chạy **LiveKit** (máy chủ chuyển tiếp camera/mic — SFU) trên máy local bằng **Docker**, ghim phiên bản, mở đúng cổng — để các Task sau đo được **gói tin thật**.

## 2. KHÁI NIỆM CẦN BIẾT

| Khái niệm | Giải thích |
|---|---|
| **SFU (LiveKit)** | Máy chủ nhận luồng camera/mic từ người phát và chuyển cho người nhận. Máy chủ Node **không** tự truyền media |
| **RTP / cổng UDP** | Gói media đi qua **UDP** (dải 50000–50100). Thiếu cấu hình dải cổng ⇒ "kết nối thành công" mà **không có gói tin** (lỗi `F-28` lần trước) |
| **Ghim phiên bản** | Ghi đúng số phiên bản image (ví dụ `v1.x.y`) — **cấm** `latest` (mỗi lần kéo về có thể khác) |
| **Ngữ cảnh an toàn** | Trình duyệt chỉ cho camera/mic trên `https://` hoặc `localhost`. Điện thoại vào qua IP nội bộ cần HTTPS local |

## 5. HƯỚNG DẪN LÀM TỪNG BƯỚC
1. `infra/compose.yaml`: `livekit/livekit-server:<phiên bản cụ thể>`; cổng `7880` (HTTP/WS), `7881/tcp` (RTC TCP), `50000-50100/udp` (RTC) — ghi comment giải thích từng cổng.
2. `infra/livekit.yaml`:
   ```yaml
   port: 7880
   rtc:
     tcp_port: 7881
     port_range_start: 50000
     port_range_end: 50100
     use_external_ip: false
     node_ip: 127.0.0.1
   keys: # đọc từ env LIVEKIT_API_KEY / LIVEKIT_API_SECRET — KHÔNG commit khoá thật
   ```
3. Script gốc: `media:start` (`docker compose -f infra/compose.yaml up -d livekit`), `media:stop`, `media:status`.
4. `.env.example`: `LIVEKIT_API_KEY=devkey`, `LIVEKIT_API_SECRET=devsecret-change-me` (chỉ dev/test).
5. README: yêu cầu Docker, lệnh, cổng cần mở trên firewall, kiểm `curl http://127.0.0.1:7880` ⇒ OK; ghi chú HTTPS local (mkcert 🟡) khi thử điện thoại thật.
