**Việc cần làm:** `GET /healthz` (`@Public()`) → `{ db: 'ok'|'fail', aiWorker: 'ready'|'restarting'|'down', bootId, version }`, HTTP 200 chỉ khi cả hai ok (ngược lại 503). DB: `select 1` qua pool (timeout 1 s). AI: supervisor nhận `READY` trong 10 s gần nhất. Không lộ bí mật/stack trace. Giữ `/health` (liveness) như cũ. Server chỉ nhận lệnh sau khi xử lý ván cũ INTERRUPTED (ST11.2) xong ⇒ readiness false tới lúc đó. Test tích hợp: tắt DB ⇒ 503; kill AI child ⇒ `restarting` rồi `ready`.
