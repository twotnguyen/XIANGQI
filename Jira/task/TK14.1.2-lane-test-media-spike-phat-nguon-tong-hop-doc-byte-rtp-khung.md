**Việc cần làm:**
1. `vitest.media.config.ts` (`include: tests/media/**/*.test.ts`, `passWithNoTests: false`, timeout 60 s); script `test:media` chuyển tiếp tham số.
2. `tests/media/helpers/livekit.ts`: tạo token bằng `livekit-server-sdk` (khoá từ env); hàm kiểm LiveKit sống — **không** sống ⇒ `throw` (test đỏ, không skip).
3. `tests/media/helpers/browser-peer.ts`: mở Chromium bằng Playwright với cờ `--use-fake-device-for-media-stream --use-fake-ui-for-media-stream`, nạp trang tối giản (`tests/media/fixtures/peer.html` dùng `livekit-client` bản ghim) để: kết nối phòng, publish camera+mic giả (nguồn tổng hợp), hoặc subscribe.
4. `tests/media/helpers/stats.ts`: đọc `RTCPeerConnection.getStats()` của bên nhận: `inbound-rtp` kind video → `bytesReceived`, `framesDecoded`; kind audio → `bytesReceived`; **chờ có điều kiện** (poll mỗi 250 ms tới khi > 0 hoặc hết 20 s) — **không** chờ cố định.
5. `tests/media/spike.test.ts`: A publish, B subscribe cùng phòng ⇒ assert video bytes > 0, frames > 0, audio bytes > 0; in số thực tế ra log để ghi báo cáo. ⛔ Không assert object tự tạo.
6. Thêm job `media` vào CI: khởi động LiveKit bằng compose, cài Chromium, chạy `pnpm test:media`.
7. Không lưu media thật/video vào repo hay artifact.

**Bẫy dễ gặp:** test media "chỉ kiểm object token tự tạo" (lần trước `F-14`); harness không chạy được bằng lệnh nào (`F-10`).
