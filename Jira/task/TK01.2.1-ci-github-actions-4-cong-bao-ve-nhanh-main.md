**Mục tiêu:** Mọi PR vào `main` đều qua 4 cổng; **không có cách bỏ qua test âm thầm**.

**Việc cần làm:**
1. `.github/workflows/ci.yml`, kích hoạt `pull_request` vào `main` và `push` lên `main`.
2. Pin **chính xác** phiên bản Node (ví dụ `24.x.y` đầy đủ, không phải `24`) bằng `actions/setup-node`; bật cache pnpm store.
3. `pnpm install --frozen-lockfile` (cấm `--no-frozen-lockfile`).
4. Các bước tuần tự, **dừng ngay khi đỏ**: `pnpm lint` → `pnpm typecheck` → `pnpm build` → `pnpm test:unit`.
5. Bước chặn test bị bỏ qua: chạy Vitest với reporter JSON (`--reporter=json --outputFile=artifacts/unit.json`), script đọc file, nếu `numPendingTests + numTodoTests > 0` thì exit 1 và in tên test.
6. Bước chặn `.only`: `grep -rnE '\.(only)\(' tests packages apps --include=*.ts --include=*.tsx` có kết quả ⇒ exit 1.
7. Job e2e: cài Chromium, `pnpm test:e2e` (cả 2 project); thất bại thì upload `test-results/` làm artifact.
8. Trên GitHub: Settings → Branches → rule cho `main`: *Require status checks to pass* (chọn job CI), *Require pull request before merging*, cấm force push.
9. Thêm badge CI vào README.

**File/module:** `.github/workflows/ci.yml`, `scripts/check-no-skip.mjs`.

**Bẫy dễ gặp:** đếm skip bằng cách grep text output dễ sai theo phiên bản Vitest — dùng reporter JSON. Quên bật branch protection thì CI đỏ vẫn merge được.

**Bàn giao:** CI chạy trên mọi PR; link workflow trong README. Các lane integration/media/load sẽ được thêm vào CI ở TK01.2.2, TK14.1.2, TK16.4.1.

**Tự kiểm:** mở một PR nháp sạch, CI xanh ≤ 10 phút.
