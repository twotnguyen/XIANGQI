## 1. MỤC TIÊU (đọc trong 1 phút)

Dựng **CI** (Continuous Integration — tích hợp liên tục) trên GitHub Actions: **mỗi PR** tự động chạy 4 cổng `lint → typecheck → build → test:unit` + e2e smoke. Bất kỳ cổng nào đỏ ⇒ **không merge được** vào `main`.

Thêm 2 chốt chặn đặc biệt của dự án: **cấm test bị bỏ qua** (`.skip`) và **cấm `.only`**.

## 2. KHÁI NIỆM CẦN BIẾT

| Khái niệm | Giải thích |
|---|---|
| **CI / GitHub Actions** | Máy của GitHub tự chạy lệnh mỗi khi có PR/push, theo file `.github/workflows/*.yml` |
| **Job / step** | Job = một máy chạy; step = một lệnh trong job. Step đỏ ⇒ dừng job |
| **Branch protection** | Luật trên GitHub cho nhánh `main`: phải qua PR, phải CI xanh, cấm force push |
| **Artifact** | File CI lưu lại để tải về xem (ví dụ trace Playwright khi test lỗi) |
| **Vì sao chặn `.skip`/`.only`** | `.only` làm chỉ 1 test chạy, còn lại bị bỏ qua mà không ai biết; `.skip` giấu test đỏ. Cả hai tạo "xanh giả" — Luật tuyệt đối số 6 |

**Từ kỹ thuật cần tra:** [Test skip / .only](../05-TU-DIEN-KY-THUAT.md#skip) · [Unit/Integration/E2E](../05-TU-DIEN-KY-THUAT.md#test-lanes)

## 5. HƯỚNG DẪN LÀM TỪNG BƯỚC

### 5.1 `.github/workflows/ci.yml`
```yaml
name: CI
on:
  pull_request: { branches: [main] }
  push: { branches: [main] }
jobs:
  quality:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4          # đọc phiên bản từ "packageManager"
      - uses: actions/setup-node@v4
        with: { node-version: '24.x.y', cache: 'pnpm' }   # ghi ĐẦY ĐỦ số, trùng engines.node
      - run: pnpm install --frozen-lockfile
      - name: Chặn .only
        run: |
          if grep -rnE '\.only\(' tests packages apps --include=*.ts --include=*.tsx; then
            echo "::error::Có .only — xoá trước khi merge"; exit 1; fi
      - run: pnpm lint
      - run: pnpm typecheck
      - run: pnpm build
      - name: Unit test (xuất JSON để đếm skip)
        run: pnpm test:unit -- --reporter=default --reporter=json --outputFile=artifacts/unit.json
      - name: Chặn test bị bỏ qua
        run: node scripts/check-no-skip.mjs artifacts/unit.json
  e2e:
    needs: quality
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with: { node-version: '24.x.y', cache: 'pnpm' }
      - run: pnpm install --frozen-lockfile
      - run: pnpm exec playwright install --with-deps chromium
      - run: pnpm build
      - run: pnpm test:e2e
      - if: failure()
        uses: actions/upload-artifact@v4
        with: { name: e2e-test-results, path: test-results/ }
```
(Tên action và phiên bản `@v4` là 🟡 — dùng bản ổn định hiện hành, **ghi cụ thể**.)

### 5.2 `scripts/check-no-skip.mjs`
```js
import { readFileSync } from 'node:fs';
const r = JSON.parse(readFileSync(process.argv[2], 'utf8'));
const skipped = [];
for (const file of r.testResults ?? []) for (const t of file.assertionResults ?? [])
  if (t.status === 'pending' || t.status === 'skipped' || t.status === 'todo') skipped.push(`${file.name} › ${t.fullName}`);
if (skipped.length) { console.error(`Có ${skipped.length} test bị bỏ qua:\n` + skipped.join('\n')); process.exit(1); }
console.log('0 test bị bỏ qua');
```
Đọc **file JSON** thay vì grep chữ trong output (chữ thay đổi theo phiên bản Vitest).

### 5.3 Bật bảo vệ nhánh `main` (trên github.com)
*Settings → Branches → Add branch ruleset* (hoặc *Branch protection rule*) cho `main`:
- ☑ Require a pull request before merging → **Require approvals: 1** (người duyệt khác người mở PR — [AGENTS.md §8.3](../../AGENTS.md))
- ☑ Require status checks to pass → chọn `quality` và `e2e`
- ☑ Block force pushes
Chụp ảnh màn hình cấu hình, đính vào PR.
