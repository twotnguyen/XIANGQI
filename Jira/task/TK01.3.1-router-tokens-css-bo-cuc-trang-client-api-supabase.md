**Đầu vào cần có:** thiết kế design system từ TK02.1.1 (token, thành phần nút/ô nhập/hộp thoại/toast, bố cục khung trang máy tính và điện thoại).

**Việc cần làm:**
1. `apps/web/src/styles/tokens.css` — biến CSS toàn cục, **chép đúng**:
   ```css
   :root{
     --color-paper:#F5E8CC;  /* nền giấy – nền trang */
     --color-wood:#D8AE72;   /* gỗ sáng – mặt bàn */
     --color-wood-edge:#704525; /* gỗ viền – viền bàn, đường kẻ */
     --color-ink:#28221C;    /* mực – chữ chính */
     --color-red:#A51F25;    /* quân đỏ */
     --color-black:#24201C;  /* quân đen */
     --color-focus:#155E75;  /* viền tiêu điểm bàn phím */
     --space-1:4px; --space-2:8px; --space-3:12px; --space-4:16px; --space-6:24px; --space-8:32px;
     --touch-min:44px;
   }
   ```
   Font giao diện: font hệ thống hỗ trợ tiếng Việt có dấu (`system-ui, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif`). **Không** tải font từ dịch vụ ngoài. Viền tiêu điểm: `:focus-visible { outline: 3px solid var(--color-focus); outline-offset: 2px; }`.
2. `apps/web/src/app/router.tsx` (React Router) với các route (component placeholder "Đang xây dựng" có tiêu đề trang):
   `/login`, `/register`, `/forgot-password`, `/reset-password`, `/verify`, `/onboarding`, `/auth/callback`, `/lobby`, `/friends`, `/invitations`, `/rooms/:id`, `/rooms/:roomId/replay/:matchId`, `/ai/new`, `/ai/:id`, `/history`, `/history/:id`, `/settings`, `/join`. `/` chuyển tới `/lobby`.
3. `RequireAuth` (tạm đọc phiên từ Supabase client): chưa đăng nhập ⇒ chuyển `/login?next=<đường dẫn hiện tại đã encode>`. Chỉ chấp nhận `next` là đường dẫn nội bộ bắt đầu bằng `/` (chống chuyển hướng ra ngoài).
4. `apps/web/src/app/AppLayout.tsx`: thanh điều hướng (logo "Cờ Tướng Online", link Sảnh, Bạn bè, Lịch sử, chỗ trống cho chỉ báo lời mời, menu hồ sơ) + vùng nội dung; máy tính ≥ 1024px thanh ngang, điện thoại menu ☰. CSS Modules cho từng component.
5. `apps/web/src/app/providers.tsx`: `QueryClientProvider` (TanStack Query), toaster `sonner` (vị trí không che góc dưới nơi sau này đặt nút Đầu hàng — chọn `top-center`).
6. `apps/web/src/lib/api.ts`: hàm `apiFetch(path, init)` gắn `Authorization: Bearer <access token>` lấy từ Supabase session, base URL từ `VITE_API_URL`, parse lỗi dạng `{ code, message }` thành `ApiError`; **không** dùng cookie liên miền (`credentials: 'omit'`).
7. `apps/web/src/lib/supabase.ts`: tạo client từ `VITE_SUPABASE_URL` + `VITE_SUPABASE_PUBLISHABLE_KEY`, `flowType: 'pkce'`.
8. Thành phần dùng chung theo thiết kế TK02.1.1: `Button` (có trạng thái `loading` = vô hiệu + chữ "Đang xử lý…"), `TextField` (nhãn, lỗi tiếng Việt dưới ô), `Dialog` (đóng bằng X / Esc / bấm ra ngoài, có prop `dismissible=false` cho 4 hộp thoại không đóng tuỳ ý), `Skeleton`, `EmptyState`, `ErrorState` (nút "Thử lại"), `DisabledReason` (dòng giải thích vì sao nút vô hiệu).

**File/module:** `apps/web/src/styles/tokens.css`, `apps/web/src/app/{router,AppLayout,providers,RequireAuth}.tsx`, `apps/web/src/lib/{api,supabase}.ts`, `apps/web/src/components/ui/*`.

**Không làm:** nội dung các màn hình (các Story sau), logic xác thực thật (EP06).

**Bẫy dễ gặp:** tự "chỉnh cho đẹp" mã màu → phá số đo tương phản (quân đỏ trên gỗ chỉ 3,62:1, ngưỡng 3:1). `next` nhận URL ngoài (`https://evil`) → lỗ hổng chuyển hướng mở.

**Bàn giao:** danh sách component UI + cách dùng (comment đầu file); route map cho các Task FE sau.

**Tự kiểm:** `pnpm lint && pnpm typecheck && pnpm build`; mở `/lobby` khi chưa đăng nhập ⇒ về `/login?next=%2Flobby`.
