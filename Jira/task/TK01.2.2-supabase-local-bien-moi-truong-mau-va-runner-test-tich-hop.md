## 1. MỤC TIÊU (đọc trong 1 phút)

1. Chạy **Supabase ở máy mình** (PostgreSQL + đăng nhập + hộp thư email giả) bằng Docker, **bật xác minh email**.
2. Liệt kê **mọi biến môi trường** trong `.env.example` và phân biệt biến **bí mật** / **công khai**.
3. Bật lane **`pnpm test:integration`** chạy trên **PostgreSQL thật**; thiếu DB ⇒ **đỏ**, không bỏ qua.

## 5. HƯỚNG DẪN LÀM TỪNG BƯỚC

### 5.1 Khởi tạo
```bash
supabase init            # tạo thư mục supabase/
```
Trong `supabase/config.toml` (các cổng mặc định của CLI — kiểm lại cho đúng):

| Mục | Cổng |
|---|---|
| API (Auth, REST) | `54321` |
| PostgreSQL | `54322` |
| Studio | `54323` |
| Hộp thư (Inbucket/Mailpit) | `54324` |

Bật xác minh email — **bắt buộc**:
```toml
[auth.email]
enable_confirmations = true
```

### 5.2 Script gốc
| Script | Lệnh |
|---|---|
| `db:start` | `supabase start` |
| `db:stop` | `supabase stop` |
| `db:reset` | `supabase db reset` (xoá DB local, áp lại **mọi** migration) |
| `db:status` | `supabase status` |

### 5.4 Lane integration

`vitest.integration.config.ts`:
```ts
import { defineConfig } from 'vitest/config';
export default defineConfig({
  test: {
    include: ['tests/integration/**/*.test.ts'],
    passWithNoTests: false,
    fileParallelism: false,     // các file dùng chung DB ⇒ chạy lần lượt
    testTimeout: 30_000,        // timeout chống treo, KHÔNG phải cách chờ nghiệp vụ
  },
});
```
Script `test:integration` = `vitest run --config vitest.integration.config.ts`.

`tests/integration/setup/db.ts`:
```ts
import pg from 'pg';
export async function connectTestDb(): Promise<pg.Client> {
  const url = process.env.DATABASE_URL;
  if (!url) throw new Error('Thiếu DATABASE_URL — chạy pnpm db:start và tạo .env');
  const u = new URL(url);
  if (!['127.0.0.1', 'localhost'].includes(u.hostname)) throw new Error('Test tích hợp chỉ chạy trên DB local');
  const c = new pg.Client({ connectionString: url });
  await c.connect();                     // không kết nối được ⇒ ném lỗi ⇒ test ĐỎ
  return c;
}
```
`tests/integration/smoke.db.test.ts`: `[T034-01] select 1 trả 1`; `[T034-02] PostgreSQL phiên bản ≥ 15` (đọc `server_version_num`).

### 5.5 CI — thêm job `integration`
```yaml
  integration:
    needs: quality
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: supabase/setup-cli@v1
        with: { version: <ghi số cụ thể> }
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with: { node-version: '24.x.y', cache: 'pnpm' }
      - run: pnpm install --frozen-lockfile
      - run: supabase start
      - run: pnpm test:integration
        env: { DATABASE_URL: postgresql://postgres:postgres@127.0.0.1:54322/postgres }
```
Thêm `integration` vào danh sách check bắt buộc của branch protection.

## 6. BẪY DỄ GẶP

| Bẫy | Hậu quả | Cách tránh |

### B. Các ca kiểm thử

#### QA01.2.2-01 · Supabase local chạy đủ 4 dịch vụ
- **Các bước:** `pnpm db:start` → `pnpm db:status`.
- **Mong đợi:** output có `API URL: http://127.0.0.1:54321`, `DB URL: postgresql://…:54322/postgres`, `Studio URL: http://127.0.0.1:54323`, và URL hộp thư cổng `54324`.

#### QA01.2.2-02 · Studio và hộp thư mở được
- **Các bước:** mở http://127.0.0.1:54323 và http://127.0.0.1:54324 trên trình duyệt.
- **Mong đợi:** cả hai trang mở được (Studio hiện giao diện quản trị; hộp thư hiện danh sách email — có thể rỗng).

#### QA01.2.2-03 · Lane integration chạy trên DB thật ⭐
- **Các bước:** `pnpm test:integration; echo "exit=$?"`
- **Mong đợi:** `Tests  2 passed`, không có `skipped`; `exit=0`.

#### QA01.2.2-04 · Tắt DB ⇒ test ĐỎ, không bỏ qua ⭐
- **Các bước:** `pnpm db:stop` → `pnpm test:integration; echo "exit=$?"` → `pnpm db:start`.
- **Mong đợi:** test **thất bại** với lỗi kết nối (ví dụ `ECONNREFUSED 127.0.0.1:54322`); `exit` khác 0; **không** có dòng `skipped`.

#### QA01.2.2-05 · Xác minh email đang bật
- **Các bước:** `grep -n -A2 "\[auth.email\]" supabase/config.toml`
- **Mong đợi:** có dòng `enable_confirmations = true`.

#### QA01.2.2-06 · Chỉ 3 biến công khai `VITE_*` ⭐
- **Các bước:** `grep -n "^VITE_" .env.example`
- **Mong đợi:** đúng 3 dòng: `VITE_API_URL`, `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY`. Không có chữ `SECRET` trong bất kỳ biến `VITE_*` nào.

#### QA01.2.2-07 · `.env.example` không chứa khoá thật
- **Các bước:** `pnpm db:status` ghi lại 2 khoá (publishable, secret) → `grep -F "<khoá secret vừa thấy>" .env.example; echo "exit=$?"`
- **Mong đợi:** grep **không** tìm thấy (`exit=1`).

#### QA01.2.2-08 · Test tích hợp từ chối DB không phải local
- **Các bước:** `DATABASE_URL=postgresql://u:p@example.com:5432/x pnpm test:integration; echo "exit=$?"`
- **Mong đợi:** đỏ với thông báo "Test tích hợp chỉ chạy trên DB local"; **không** thử kết nối ra ngoài.

#### QA01.2.2-09 · CI có job integration
- **Các bước:** mở PR bất kỳ gần nhất → tab **Checks**.
- **Mong đợi:** có job `integration` xanh.
