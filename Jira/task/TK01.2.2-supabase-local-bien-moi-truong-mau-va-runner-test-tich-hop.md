**Mục tiêu:** Mọi thành viên chạy được Supabase (PostgreSQL + Auth + hộp thư email) ở máy mình; có lane `test:integration` chạy trên **PostgreSQL thật**.

**Việc cần làm:**
1. Cài Supabase CLI (ghi phiên bản vào README), `supabase init`. Trong `supabase/config.toml`: API `54321`, DB `54322`, Studio `54323`, hộp thư (Inbucket/Mailpit) `54324`.
2. **Bật xác minh email**: `[auth.email] enable_confirmations = true` — **không** auto-confirm. Email xác minh đi vào hộp thư local ở `http://127.0.0.1:54324`.
3. `.env.example` liệt kê đủ biến (chỉ giá trị mẫu, ví dụ `DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:54322/postgres`):
   | Biến | Dùng ở | Bí mật |
   |---|---|---|
   | `DATABASE_URL` | server | ✅ |
   | `SUPABASE_URL` | server | — |
   | `SUPABASE_SECRET_KEY` | server | ✅ |
   | `SUPABASE_PUBLISHABLE_KEY` | server + web | — |
   | `APP_ORIGIN` | server (CORS) | — |
   | `PORT` | server | — |
   | `INVITE_HMAC_KEY` | server | ✅ |
   | `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET` | server | ✅ (key/secret) |
   | `AI_MAX_RUNNING` (=2), `AI_MAX_QUEUED` (=8) | server | — |
   | `VITE_API_URL`, `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY` | web | — (công khai) |
   ⛔ Không biến bí mật nào được mang tiền tố `VITE_` — mọi biến `VITE_*` nằm trong gói tải về trình duyệt.
4. Script gốc: `db:start` (`supabase start`), `db:stop`, `db:reset` (`supabase db reset` — áp lại mọi migration), `db:status`.
5. `vitest.integration.config.ts`: `include: ['tests/integration/**/*.test.ts']`, `passWithNoTests: false`, `fileParallelism: false`, `testTimeout` 30 s. Script `test:integration` chuyển tiếp tham số.
6. `tests/integration/setup/db.ts`: kết nối bằng `DATABASE_URL` (thư viện `pg`); **không kết nối được thì `throw`** (test đỏ), không `skip`.
7. `tests/integration/smoke.db.test.ts`: `select 1` trả 1; kiểm phiên bản PostgreSQL ≥ 15.
8. Thêm job `integration` vào CI: khởi động Supabase bằng CLI (`supabase start`) rồi chạy `pnpm test:integration`.

**File/module:** `supabase/config.toml`, `.env.example`, `package.json`, `vitest.integration.config.ts`, `tests/integration/setup/db.ts`, `tests/integration/smoke.db.test.ts`, `.github/workflows/ci.yml`.

**Không làm:** bảng dữ liệu (EP05), module `env.ts` (TK01.2.3), Supabase cloud.

**Bẫy dễ gặp:** viết `describe.skipIf(!process.env.DATABASE_URL)` → thiếu DB thì test "xanh" vì bị bỏ qua. Luật dự án: thiếu DB ⇒ **đỏ**.

**Bàn giao:** README mục "Chạy Supabase local" (lệnh + URL Studio + URL hộp thư); `pnpm test:integration` chạy thật cho EP05.

**Tự kiểm:** `pnpm db:start && pnpm test:integration` xanh; `pnpm db:stop && pnpm test:integration` đỏ với lỗi kết nối.
