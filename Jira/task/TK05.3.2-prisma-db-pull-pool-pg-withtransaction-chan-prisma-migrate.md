### 5.4 `db/pool.ts` + `db/transaction.ts`
```ts
// pool pg bằng DATABASE_URL (app_server)
export async function withTransaction<T>(
  fn: (client: PoolClient) => Promise<T>,
  opts?: { isolation?: 'READ COMMITTED' | 'SERIALIZABLE' },
): Promise<T> {
  const client = await pool.connect();
  try {
    await client.query(`BEGIN ISOLATION LEVEL ${opts?.isolation ?? 'READ COMMITTED'}`);
    const r = await fn(client);
    await client.query('COMMIT');
    return r;
  } catch (e) { await client.query('ROLLBACK'); throw e; }
  finally { client.release(); }
}
```

### 5.5 `docs/DB-BOUNDARY.md` — bảng ranh giới
| Dùng Prisma | Dùng SQL thuần (`withTransaction` + `FOR UPDATE`) |
|---|---|
| Hồ sơ, tên hiển thị | Đi một nước cờ |
| Bạn bè, lời mời kết bạn | Đầu hàng, xin hoà, xin đi lại |
| Lời mời phòng, mã, link (phát hành) | Nhận người vào phòng (đếm sức chứa) |
| Lịch sử tin nhắn (đọc, có điều kiện quyền đủ) | Bắt đầu ván (hai người sẵn sàng) |
| Lịch sử ván (đọc) | Gửi chat (kiểm quyền rồi ghi) |
| Danh sách sảnh | Tái đấu; mọi bộ đếm thời hạn; đuổi người xem; thu hồi quyền |
Quy tắc: cần **khoá dòng**, **thứ tự khoá**, hoặc **đếm rồi ghi** ⇒ SQL thuần. Thứ tự khoá **phòng → người → ván**. **Không** giữ khoá khi gọi ra ngoài (AI, LiveKit, email).
