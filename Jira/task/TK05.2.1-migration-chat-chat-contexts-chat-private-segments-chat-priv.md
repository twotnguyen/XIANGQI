**Bối cảnh nghiệp vụ (ghi để người làm hiểu schema):** Chat có **2 kênh**: `PLAYERS` (kênh riêng, chỉ 2 người chơi) và `ROOM` (kênh chung, người xem + người chơi). Chat có ngay từ **phòng chờ** (chưa có ván). Một **context** kéo dài từ phòng chờ → ván đầu → kết thúc; bắt đầu ván đầu chỉ gắn `match_id`, **không** copy tin. **Tái đấu** seal context cũ, tạo context mới trống. Kênh riêng chia thành **segment** = tập người được đọc trong một khoảng thời gian: chủ phòng A một mình → segment {A}; B vào → đóng {A}, mở {A,B}; B rời → đóng {A,B}, mở {A}; C vào → mở {A,C}. C **không** đọc được tin của {A,B}.

**Việc cần làm:** `<ts>_chat.sql`
1. `chat_contexts(id uuid PK, room_id uuid NOT NULL FK rooms, match_id uuid NULL FK matches UNIQUE, generation bigint NOT NULL CHECK >= 0, sealed_at timestamptz NULL, next_sequence bigint NOT NULL DEFAULT 0, created_at)`; `UNIQUE(room_id, generation)`, `UNIQUE(id, room_id)`, partial `UNIQUE(room_id) WHERE sealed_at IS NULL`.
2. FK `rooms.current_chat_context_id → chat_contexts(id)`; **deferred constraint trigger** kiểm context cùng room và chưa seal; composite FK bảo đảm match thuộc cùng room.
3. `chat_private_segments(id uuid PK, context_id uuid NOT NULL FK, opened_at, closed_at NULL)`; `UNIQUE(id, context_id)`; partial `UNIQUE(context_id) WHERE closed_at IS NULL`.
4. `chat_private_participants(segment_id FK, user_id FK profiles, membership_id uuid NOT NULL, PRIMARY KEY(segment_id, user_id))`; trigger: tối đa 2 participant/segment, **không đổi** sau khi segment đã có tin.
5. `chat_messages(id uuid PK, context_id NOT NULL FK, channel text NOT NULL CHECK IN ('PLAYERS','ROOM'), private_segment_id uuid NULL, sender_id FK profiles, sender_membership_id uuid NOT NULL, sender_is_player boolean NOT NULL, content text NOT NULL CHECK (char_length(content) BETWEEN 1 AND 1000), client_message_id uuid NOT NULL, payload_hash text NOT NULL, sequence bigint NOT NULL CHECK > 0, created_at timestamptz NOT NULL)`:
   ```sql
   CHECK ((channel='PLAYERS' AND private_segment_id IS NOT NULL AND sender_is_player)
       OR (channel='ROOM' AND private_segment_id IS NULL))
   FOREIGN KEY (private_segment_id, context_id) REFERENCES chat_private_segments(id, context_id)
   UNIQUE (context_id, sender_id, client_message_id)   -- chống gửi trùng, không phụ thuộc match_id
   UNIQUE (context_id, sequence)
   ```
   Deferred trigger: sender kênh PLAYERS phải là participant của segment đó.
6. Index: `(context_id, channel, sequence DESC)`; participants `(user_id, membership_id, segment_id)`; messages `(private_segment_id, sequence DESC)`; `(created_at)` cho dọn 30 ngày.
7. `ENABLE ROW LEVEL SECURITY` cả 4 bảng, **không** policy cho anon/authenticated.
8. Không cascade xoá tin khi thành viên rời.
9. Test `tests/integration/issue-040.test.ts` (12 ca ở TK05.2.1).

**Bẫy dễ gặp:** đặt khoá chống trùng có `match_id` nullable ⇒ NULL không bằng NULL nên UNIQUE không chặn được lúc chưa có ván.
