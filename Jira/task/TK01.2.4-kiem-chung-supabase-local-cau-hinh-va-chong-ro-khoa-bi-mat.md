## 1. MỤC TIÊU

Kiểm **độc lập, trên máy Tester**, 3 lời hứa của Story ST01.2 trước khi cả nhóm bắt đầu làm DB (EP05):
1. Supabase local chạy đủ và **bật xác minh email**.
2. Test tích hợp chạy trên **PostgreSQL thật** và **đỏ khi thiếu DB**.
3. **Khoá bí mật không rò** — không vào log, không vào gói JavaScript của web, không vào file mẫu.

## 2. ĐIỀU KIỆN BẮT ĐẦU

- [ ] TK01.2.2 và TK01.2.3 đã **Done**.
- [ ] Docker Desktop, Supabase CLI đã cài trên máy Tester.

## 3. MÔI TRƯỜNG VÀ DỮ LIỆU

1. `git checkout develop && git pull && pnpm install --frozen-lockfile`
2. `cp .env.example .env`; `pnpm db:start`; `pnpm db:status` lấy khoá, điền vào `.env` theo README.
3. Chuỗi thử bí mật dùng xuyên suốt: **`sk_test_BI_MAT_123`**.
