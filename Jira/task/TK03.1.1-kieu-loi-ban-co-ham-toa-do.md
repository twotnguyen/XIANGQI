## 1. MỤC TIÊU (đọc trong 1 phút)

Viết **kiểu dữ liệu lõi của bàn cờ** (bên, loại quân, ô, quân, bàn, nước đi, thế cờ) và **các hàm toạ độ** trong gói `@xiangqi/contracts`. Đây là "từ vựng" mà web, server và AI cùng dùng — sai ở đây là sai toàn bộ.

Điểm quan trọng nhất: **hệ toạ độ** phải đúng đặc tả — lần xây trước đã làm **ngược** và phát hiện quá muộn.

## 2. KHÁI NIỆM CẦN BIẾT

**Hệ toạ độ dự án (`GR-COORD`, `DEC-003`) — học thuộc:**
```
        x=0  1   2   3   4   5   6   7   8
y=0   車 馬 象 士 將 士 象 馬 車   ← ĐEN, hàng cuối (TRÊN CÙNG)
y=1   ·   ·   ·   ·   ·   ·   ·   ·   ·      cung ĐEN: x 3–5, y 0–2
y=2   ·  砲  ·   ·   ·   ·   ·  砲  ·
y=3   卒  ·  卒  ·  卒  ·  卒  ·  卒
y=4   ·   ·   ·   ·   ·   ·   ·   ·   ·   ← ĐEN qua sông khi y ≥ 5
      ════════ 楚 河   漢 界 ════════     ← SÔNG giữa y=4 và y=5
y=5   ·   ·   ·   ·   ·   ·   ·   ·   ·   ← ĐỎ qua sông khi y ≤ 4
y=6   兵  ·  兵  ·  兵  ·  兵  ·  兵
y=7   ·  炮  ·   ·   ·   ·   ·  炮  ·      cung ĐỎ: x 3–5, y 7–9
y=8   ·   ·   ·   ·   ·   ·   ·   ·   ·
y=9   俥 傌 相 仕 帥 仕 相 傌 俥   ← ĐỎ, hàng cuối (DƯỚI CÙNG)
```
- `(x, y)` đếm từ 0; x 0→8 **trái sang phải**; y 0→9 **trên xuống dưới**.
- **ĐEN ở trên (y=0), ĐỎ ở dưới (y=9). ĐỎ đi trước.**
- Chỉ số mảng = `y * 9 + x`, mảng đúng **90** phần tử. Ví dụ `(0,0)` ⇒ 0; `(4,0)` ⇒ 4; `(4,9)` ⇒ 85; `(8,9)` ⇒ 89.
- Người cầm Đen thấy bàn **lật** — chỉ là hiển thị, toạ độ **không đổi**.

| Khái niệm | Giải thích |
|---|---|
| **Kiểu (type)** | Khai báo hình dạng dữ liệu cho TypeScript kiểm lúc biên dịch |
| **`readonly`** | Không cho sửa. `Board` là `readonly` ⇒ muốn "đi quân" phải tạo mảng mới — tránh lỗi sửa nhầm thế cờ gốc |
| **Hàm thuần** | Cùng đầu vào ⇒ cùng kết quả, không sửa tham số, không dùng biến toàn cục |
| **Qua sông** | ĐỎ (ở dưới) qua sông khi **y ≤ 4**; ĐEN (ở trên) qua sông khi **y ≥ 5** |

## 5. HƯỚNG DẪN LÀM TỪNG BƯỚC

### 5.1 `packages/contracts/src/game.ts`
Đầu file **chép nguyên** khối chú thích:
```
HỆ TOẠ ĐỘ (DEC-003):
  y = 0  → hàng TRÊN CÙNG  = hàng cuối của ĐEN
  y = 9  → hàng DƯỚI CÙNG  = hàng cuối của ĐỎ
  y tăng từ TRÊN xuống DƯỚI
  Nửa sân ĐEN: y 0..4   |   Nửa sân ĐỎ: y 5..9
  Sông giữa y=4 và y=5
  Cung ĐEN: x 3..5, y 0..2   |   Cung ĐỎ: x 3..5, y 7..9
  ĐỎ đi trước
```
Rồi khai báo:
```ts
export type Side = 'RED' | 'BLACK';
export type PieceType = 'GENERAL' | 'ADVISOR' | 'ELEPHANT' | 'HORSE' | 'ROOK' | 'CANNON' | 'PAWN';
export type Square = { x: number; y: number };      // x 0..8, y 0..9
export type Piece = { id: string; type: PieceType; side: Side };
export type Board = readonly (Piece | null)[];      // đúng 90 phần tử, chỉ số = y*9+x
export type Move = { from: Square; to: Square };
export type Position = { board: Board; turn: Side };
export const BOARD_WIDTH = 9;
export const BOARD_HEIGHT = 10;
export const BOARD_SIZE = 90;
export const RULE_SET_VERSION = 'xiangqi-simple-v1';
export const opposite = (s: Side): Side => (s === 'RED' ? 'BLACK' : 'RED');
```

### 5.2 `packages/contracts/src/coordinates.ts`

| Hàm | Quy tắc | Ví dụ |
|---|---|---|
| `squareToIndex(sq)` | `y * 9 + x` | `(4,9)` ⇒ 85 |
| `indexToSquare(i)` | `{ x: i % 9, y: Math.floor(i / 9) }` | 85 ⇒ `(4,9)` |
| `isOnBoard(sq)` | x, y là **số nguyên** (`Number.isInteger`), 0 ≤ x ≤ 8, 0 ≤ y ≤ 9 | `(1.5,0)`, `(NaN,0)`, `(-1,0)`, `(9,0)` ⇒ false |
| `isInPalace(sq, side)` | ĐEN: x 3..5 **và** y 0..2 · ĐỎ: x 3..5 **và** y 7..9 | `(4,0)`/BLACK ⇒ true; `(4,9)`/RED ⇒ true |
| `isOwnHalf(sq, side)` | ĐEN: y 0..4 · ĐỎ: y 5..9 | `(0,4)`/BLACK ⇒ true |
| `hasCrossedRiver(sq, side)` | ĐỎ: `y ≤ 4` · ĐEN: `y ≥ 5` | `(0,4)`/RED ⇒ true; `(0,5)`/RED ⇒ false |
| `sameSquare(a, b)` | so cả x và y | |
