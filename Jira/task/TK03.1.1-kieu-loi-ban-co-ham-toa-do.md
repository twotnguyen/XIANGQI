**Việc cần làm:**
1. `packages/contracts/src/game.ts` — đầu file **chép nguyên** khối chú thích hệ toạ độ:
   ```
   HỆ TOẠ ĐỘ (DEC-003):
     y = 0  → hàng TRÊN CÙNG  = hàng cuối của ĐEN
     y = 9  → hàng DƯỚI CÙNG  = hàng cuối của ĐỎ
     y tăng từ TRÊN xuống DƯỚI
     Nửa sân ĐEN: y 0..4   |   Nửa sân ĐỎ: y 5..9
     Sông giữa y=4 và y=5
     Cung ĐEN: x 3..5, y 0..2   |   Cung ĐỎ: x 3..5, y 7..9
     ĐỎ đi trước
   ```
   Rồi khai báo:
   ```ts
   export type Side = 'RED' | 'BLACK';
   export type PieceType = 'GENERAL' | 'ADVISOR' | 'ELEPHANT' | 'HORSE' | 'ROOK' | 'CANNON' | 'PAWN';
   export type Square = { x: number; y: number };      // x 0..8, y 0..9
   export type Piece = { id: string; type: PieceType; side: Side };
   export type Board = readonly (Piece | null)[];      // đúng 90 phần tử
   export type Move = { from: Square; to: Square };
   export type Position = { board: Board; turn: Side };
   export const BOARD_WIDTH = 9;
   export const BOARD_HEIGHT = 10;
   export const BOARD_SIZE = 90;
   export const RULE_SET_VERSION = 'xiangqi-simple-v1';
   ```
2. `packages/contracts/src/coordinates.ts` — hàm thuần:
   | Hàm | Quy tắc |
   |---|---|
   | `squareToIndex(sq)` | `y * 9 + x` |
   | `indexToSquare(i)` | `{ x: i % 9, y: Math.floor(i / 9) }` |
   | `isOnBoard(sq)` | x, y là **số nguyên**, 0 ≤ x ≤ 8, 0 ≤ y ≤ 9; từ chối `1.5`, `NaN`, âm |
   | `isInPalace(sq, side)` | ĐEN: x 3..5, y 0..2 · ĐỎ: x 3..5, y 7..9 |
   | `isOwnHalf(sq, side)` | ĐEN: y 0..4 · ĐỎ: y 5..9 |
   | `hasCrossedRiver(sq, side)` | ĐỎ: `y ≤ 4` · ĐEN: `y ≥ 5` |
   | `sameSquare(a, b)` | so x và y |
3. Export tất cả từ `packages/contracts/src/index.ts`.
4. Unit test (tối thiểu):
   - `BOARD_SIZE === 90 === BOARD_WIDTH * BOARD_HEIGHT`; `RULE_SET_VERSION === 'xiangqi-simple-v1'`.
   - Gán `board[0] = null` trên kiểu `Board` **không biên dịch** (dùng `// @ts-expect-error`).
   - Vòng lặp đủ 90 chỉ số: `squareToIndex(indexToSquare(i)) === i`.
   - `squareToIndex({x:0,y:0}) === 0`, `({x:8,y:9}) === 89`.
   - `isOnBoard` false với x=-1, x=9, y=-1, y=10, x=1.5, NaN.
   - Cung ĐEN: (3,0),(4,1),(5,2) true; (3,3),(2,1),(6,1) false. Cung ĐỎ: (3,7),(4,8),(5,9) true; (4,6) false.
   - `hasCrossedRiver` ĐỎ: y=4 **true**, y=5 **false**; ĐEN: y=5 **true**, y=4 **false**.

**Không làm:** logic sinh nước; Zod.

**Bẫy dễ gặp:** nhầm chiều sông của ĐỎ (ĐỎ ở dưới nên qua sông là y **giảm** xuống ≤ 4). Nếu sai, tốt đi sai và AI học sai.
