## 3. CÁCH LÀM
1. **Đối chiếu R01–R19**: mỗi yêu cầu → tài liệu · Story/Task · **test cụ thể** (đường dẫn + tên) · kết quả · bằng chứng. ⛔ Không gán một test chung cho cả module.
2. **Chạy toàn bộ lane** (ghi tổng test, pass/fail/**skip = 0**, lệnh, môi trường):
   ```bash
   pnpm lint && pnpm typecheck && pnpm build && pnpm test:unit && pnpm test:integration && pnpm test:e2e && pnpm test:ai && pnpm test:media
   ```
   (+ kết quả `test:load` từ TK16.4.1).
3. **6 kịch bản hồi quy:**
   | # | Lỗi lần trước | Kiểm |

   | 1 | `F-01` | đi nước mới sau đi lại — không lỗi trùng khoá |
   | 2 | `F-02` | đếm lặp chỉ nhánh hiệu lực |
   | 3 | `F-03` | vào phòng bằng mã không bỏ qua kiểm riêng tư |
   | 4 | `F-07` | thu hồi quyền người xem có hiệu lực thật |
   | 5 | `F-11`/`F-12` | test DB chạy PostgreSQL thật; tắt DB ⇒ đỏ |
   | 6 | `F-14` | media đo byte RTP thật |
4. `grep -rn "\.only(" tests packages apps` ⇒ không có.
5. Hạng mục Internet (Google thật, SMTP ra ngoài, camera/mic 2 mạng) ⇒ **CHỜ — kiểm ở TK16.6.1**.
