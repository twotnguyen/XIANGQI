## 1. MỤC TIÊU (đọc trong 1 phút)

Viết module **đọc và kiểm tra cấu hình** cho máy chủ (`env.ts`). Khi server khởi động:
- Thiếu hoặc sai biến bắt buộc ⇒ **dừng ngay** với thông báo tiếng Việt nêu **tên** biến và lý do.
- Thông báo **không bao giờ in giá trị** của biến (có thể là khoá bí mật).
- Mọi service khác lấy cấu hình qua `ConfigService`, **không** đọc `process.env` rải rác.

## 2. KHÁI NIỆM CẦN BIẾT

| Khái niệm | Giải thích |
|---|---|
| **Fail fast** | Sai cấu hình thì chết ngay lúc khởi động, thay vì chạy tiếp rồi lỗi khó hiểu khi có người dùng |
| **Zod** | Thư viện kiểm dữ liệu theo khuôn; ở đây kiểm `process.env` |
| **Rò bí mật qua log** | Lỗi Zod mặc định có thể kèm **giá trị nhận được** — in cả object lỗi là lộ khoá vào log |
| **NestJS module / inject** | Nest tạo sẵn đối tượng `ConfigService` và "tiêm" vào constructor của service khác |

**Từ kỹ thuật cần tra:** [Zod & .strict()](../05-TU-DIEN-KY-THUAT.md#zod)

### 5.2 `env.ts`
```ts
import { z } from 'zod';
const EnvSchema = z.object({ /* theo bảng 5.1, dùng z.coerce.number() cho số */ })
  .superRefine((e, ctx) => { /* bộ ba LiveKit: có 1 thì phải đủ 3 */ });
export type AppEnv = z.infer<typeof EnvSchema>;

export class EnvError extends Error {}
export function loadEnv(source: Record<string, string | undefined> = process.env): AppEnv {
  const r = EnvSchema.safeParse(source);
  if (r.success) return r.data;
  // CHỈ in đường dẫn + thông điệp, KHÔNG in giá trị nhận được
  const lines = r.error.issues.map((i) => `- ${i.path.join('.') || '(chung)'}: ${i.message}`);
  throw new EnvError(`Cấu hình máy chủ không hợp lệ:\n${lines.join('\n')}`);
}
```
Viết thông điệp tiếng Việt cho từng luật (ví dụ `z.string({ required_error: 'bắt buộc' })`, `.min(32, 'phải dài ít nhất 32 ký tự')`).

### 5.3 `main.ts`
```ts
let env: AppEnv;
try { env = loadEnv(); } catch (e) {
  console.error(e instanceof EnvError ? e.message : 'Lỗi đọc cấu hình');
  process.exit(1);
}
// sau đó mới NestFactory.create(...)
```

### 5.4 `config.module.ts`
Module Nest **global** cung cấp `ConfigService` với hàm `get<K extends keyof AppEnv>(k: K): AppEnv[K]`. Service khác inject `ConfigService`, không đụng `process.env`.
