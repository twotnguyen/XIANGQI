## 1. MỤC TIÊU (đọc trong 1 phút)

Viết **hàm lượng giá** `evaluate(position)`: chấm điểm một thế cờ — số dương nghĩa là **bên đến lượt** đang có lợi. Đây là "con mắt" của máy cờ: thuật toán tìm kiếm (TK04.2.x) nhìn trước vài nước rồi dùng hàm này chấm các thế ở cuối.

Hàm phải: **đối xứng** (đổi lượt ⇒ đổi dấu), **nhanh** (được gọi hàng trăm nghìn lần mỗi giây), **không cấp phát bộ nhớ** trong vòng lặp.

## 2. KHÁI NIỆM CẦN BIẾT

| Khái niệm | Giải thích |
|---|---|
| **Centipawn** | Đơn vị điểm; 100 ≈ giá trị một Tốt chưa qua sông |
| **Vật chất** | Tổng giá trị quân còn trên bàn |
| **Bảng vị trí (PST — piece-square table)** | Mỗi loại quân có bảng 90 ô cộng/trừ điểm theo vị trí (ví dụ Mã ở giữa bàn tốt hơn ở góc) |
| **Linh hoạt** | Quân có nhiều chỗ đi thì tốt hơn |
| **An toàn tướng** | Tướng bị chiếu, mất Sĩ/Tượng ⇒ trừ điểm |
| **Góc nhìn bên đến lượt** | Tính (ĐỎ − ĐEN); nếu lượt ĐEN thì đổi dấu. Nhờ vậy thuật toán negamax (TK04.2.1) dùng một công thức cho cả hai bên |
| **Không cấp phát trong vòng lặp nóng** | Không `map`, `filter`, `reduce`, spread, object tạm — mỗi lần cấp phát làm bộ gom rác (GC) chạy, AI chậm hẳn. Đây là **nguyên nhân số 1** khiến AI không đạt cổng depth 6 |

### 5.2 Bảng vị trí — `pst.ts`
- Viết **một bảng cho ĐỎ** mỗi loại quân (🟡 giá trị tự chọn, nhỏ: −30..+60).
- Bảng ĐEN là **phản chiếu theo trục y**: `pstBlack[y*9+x] = pstRed[(9-y)*9+x]` (ĐỎ ở dưới, ĐEN ở trên — lật trên/dưới, **không** lật trái/phải).
- Lưu bằng `Int16Array(90)` để truy cập nhanh.

### 5.3 `evaluate(position): number`
```
diểm_ĐỎ_trừ_ĐEN = vậtChất + vịTrí + linhHoạt + anToànTướng
return position.turn === 'RED' ? điểm : -điểm
```
- **Linh hoạt** (~2 điểm/nước khả dĩ): dùng cách đếm **rẻ** — ví dụ đếm ô trống Xe/Pháo/Mã với tới theo hình học. **Không** gọi `getLegalMoves` (chậm hàng chục lần).
- **An toàn tướng**: phạt khi đang bị chiếu (`isInCheck`); phạt khi mất Sĩ/Tượng (mất cả 2 Sĩ bị phạt rõ); 🟡 phạt nhẹ khi Tướng rời tâm cung không cần thiết.
- Duyệt `for (let i = 0; i < 90; i++)`; **không** `map/filter/reduce`, không object tạm.

```ts
import { createInitialPosition, getLegalMoves, applyMove } from '@xiangqi/game-rules';
function randomPosition(seed: number, plies: number) {
  let s = seed, p = createInitialPosition();
  for (let i = 0; i < plies; i++) {
    const ms = getLegalMoves(p); if (ms.length === 0) break;
    s = (s * 1103515245 + 12345) % 2147483648;          // số giả ngẫu nhiên có seed
    p = applyMove(p, ms[s % ms.length]!);
  }
  return p;
}
```
