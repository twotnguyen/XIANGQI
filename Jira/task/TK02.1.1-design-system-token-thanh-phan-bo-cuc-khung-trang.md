**Mục tiêu:** Bộ quy chuẩn thị giác dùng chung cho mọi màn hình.

**Việc cần làm:**
1. **Styles màu**: tạo đúng 7 style màu (tên + mã ở phần Nguyên tắc của Epic). Ghi kèm các cặp tương phản đã đo (không được làm xấu đi): mực/giấy 12,95:1 · mực/gỗ 7,65:1 · đỏ/gỗ **3,62:1** · đen/gỗ 7,87:1 · đường kẻ/gỗ 3,98:1 · tiêu điểm/giấy 5,99:1 · tiêu điểm/gỗ **3,54:1** · gỗ viền/giấy 6,74:1.
2. **Chữ**: thang cỡ chữ (ví dụ 12/14/16/20/24/32), độ đậm; chữ lớn ≥ 24px (hoặc ≥ 18,66px đậm) mới được áp ngưỡng 3:1.
3. **Khoảng cách**: 4, 8, 12, 16, 24, 32 px; lưới cột cho máy tính và điện thoại.
4. **Thành phần** (mỗi cái đủ trạng thái):
   | Thành phần | Trạng thái phải vẽ |
   |---|---|
   | Nút chính / phụ / nguy hiểm | thường · hover · focus (viền `#155E75` 3px, cách 2px) · **đang xử lý** (vô hiệu + chữ "Đang xử lý…") · **vô hiệu kèm dòng giải thích** |
   | Ô nhập | trống · đang nhập · lỗi (chữ lỗi tiếng Việt dưới ô, có biểu tượng, không chỉ viền đỏ) · vô hiệu |
   | Checkbox, radio, công tắc (toggle) | bật/tắt/focus/vô hiệu, có nhãn chữ |
   | Hộp thoại | tiêu đề, nội dung, nút; biến thể **đóng được** (X + Esc + bấm ngoài) và **không đóng tuỳ ý** (không có X) |
   | Hộp thoại xác nhận nguy hiểm | có dòng hậu quả in đậm, nút nguy hiểm bên phải |
   | Toast | thành công/lỗi/thông tin; vị trí **trên giữa** (không che góc dưới nơi có nút Đầu hàng) |
   | Tab | chọn/không chọn/focus |
   | Badge số (chỉ báo lời mời) | 0 (ẩn), 1–9, "9+" |
   | Skeleton | dạng dòng, thẻ, bàn cờ |
   | Trạng thái trống / lỗi / vô hiệu | khối minh hoạ + câu giải thích + nút hành động ("Thử lại", "Tạo phòng"…) |
5. **Khung trang**: máy tính 1366 — thanh điều hướng trên (logo "Cờ Tướng Online", Sảnh, Bạn bè, Lịch sử, chuông lời mời có badge, menu hồ sơ); điện thoại 360/390 — thanh trên có ☰, tên trang, chuông.
6. **Biểu tượng**: dùng bộ `lucide` (Frontend dùng `lucide-react`), ghi tên icon cho từng chỗ dùng.
7. Trang "Ghi chú bàn giao": bảng tên token → mã màu/khoảng cách để Frontend chép vào `tokens.css`.

**Bàn giao:** link file + ảnh PNG trang design system + bảng token.

**Bẫy dễ gặp:** làm nút vô hiệu chỉ bằng cách làm mờ mà không có câu giải thích → vi phạm quy tắc "vô hiệu phải giải thích vì sao". Dùng màu đỏ để báo lỗi mà không có chữ/biểu tượng.
