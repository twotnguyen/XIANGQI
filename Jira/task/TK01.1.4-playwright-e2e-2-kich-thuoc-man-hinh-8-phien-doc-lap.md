## 1. MỤC TIÊU (đọc trong 1 phút)

Bật **Playwright** để viết test **e2e** — test mở trình duyệt thật và bấm như người dùng. Cần sẵn:
- **2 kích thước màn hình:** máy tính 1366×768 và điện thoại 360×800.
- **8 phiên độc lập** cùng lúc (2 người chơi + 5 người xem + 1 người thứ 6 bị từ chối) — đủ cho kịch bản phòng đầy.
- Tự bật web + server trước khi test, **không** chờ bằng `sleep`.

## 2. KHÁI NIỆM CẦN BIẾT

| Khái niệm | Giải thích |
|---|---|
| **Playwright** | Công cụ điều khiển trình duyệt thật bằng code: mở trang, bấm nút, gõ chữ, chụp ảnh |
| **Project** | Một cấu hình chạy (ví dụ "desktop", "mobile"). Mỗi test chạy **một lần cho mỗi project** |
| **Browser context** | Một "phiên trình duyệt" riêng: cookie, localStorage riêng — như một người dùng khác. 8 người = 8 context |
| **webServer** | Cấu hình để Playwright tự chạy `pnpm dev` và **dò** tới khi URL trả lời rồi mới test |
| **Trace** | Bản ghi từng bước của test lỗi (ảnh, mạng, DOM) — mở bằng `pnpm exec playwright show-trace` để xem vì sao lỗi |

### 5.3 `tests/e2e/helpers/sessions.ts`
```ts
import type { Browser, BrowserContext } from '@playwright/test';
/** Tạo n phiên độc lập (cookie + storage riêng) — mỗi phiên là một "người". */
export async function createSessions(browser: Browser, n: number): Promise<BrowserContext[]> {
  return Promise.all(Array.from({ length: n }, () => browser.newContext()));
}
export async function closeSessions(ctxs: BrowserContext[]): Promise<void> {
  await Promise.all(ctxs.map((c) => c.close()));
}
```
