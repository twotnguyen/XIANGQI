## 1. MỤC TIÊU (đọc trong 1 phút)

Việc **cấu hình** (không viết code ứng dụng): tạo "OAuth Client" trên Google Cloud và bật nhà cung cấp Google trong Supabase, để TK06.4.2 làm nút "Đăng nhập bằng Google".
Đây là **tài nguyên ngoài**: không có tài khoản Google Cloud ⇒ ghi `blocked-external`, **không** giả lập.

## 2. KHÁI NIỆM CẦN BIẾT

| Khái niệm | Giải thích |
|---|---|
| **OAuth Client ID / Secret** | "Tên đăng nhập + mật khẩu" của **ứng dụng** với Google. Secret là **bí mật** — không commit |
| **Redirect URI** | Địa chỉ Google được phép trả người dùng về sau khi đồng ý. Với Supabase: `<SUPABASE_URL>/auth/v1/callback` |
| **Testing mode** | Màn đồng ý OAuth ở chế độ thử: chỉ email trong danh sách "Test users" đăng nhập được — đủ cho nhóm |
| **Automatic identity linking** | Supabase tự nối tài khoản Google vào tài khoản email/mật khẩu **cùng email đã xác minh** ⇒ 1 người = 1 tài khoản |

**Từ kỹ thuật cần tra:** [Token](../05-TU-DIEN-KY-THUAT.md#jwt) · [Sổ tay: tài nguyên ngoài](../04-HUONG-DAN-KIEM-THU.md)

## 4. PHẠM VI
**✅ Làm:** cấu hình Google Cloud; `supabase/config.toml` mục `[auth.external.google]`; `.env.example`; README mục "Bật Google local".
**❌ Không làm:** nút Google (TK06.4.2).

## 5. HƯỚNG DẪN LÀM TỪNG BƯỚC

1. **Google Cloud Console** → tạo project `xiangqi-online` 🟡.
2. **APIs & Services → OAuth consent screen:** User type **External**, trạng thái **Testing**; thêm email các thành viên vào **Test users**.
3. **Credentials → Create credentials → OAuth client ID → Web application.** Authorized redirect URIs:
   - `http://127.0.0.1:54321/auth/v1/callback` (local)
   - `https://<project-ref>.supabase.co/auth/v1/callback` (khi triển khai — EP16)
4. `supabase/config.toml`:
   ```toml
   [auth.external.google]
   enabled = true
   client_id = "env(GOOGLE_CLIENT_ID)"
   secret = "env(GOOGLE_CLIENT_SECRET)"
   ```
   Và `additional_redirect_urls` có `http://localhost:5173/auth/callback` (thêm URL Vercel sau).
5. `.env.example`: `GOOGLE_CLIENT_ID=` và `GOOGLE_CLIENT_SECRET=` (**để trống** / giá trị mẫu). Giá trị thật chỉ ở `.env` cá nhân hoặc kho bí mật nhóm.
6. README "Bật Google local": đặt 2 biến → `supabase stop && supabase start`.
7. Không có tài khoản Google Cloud ⇒ ghi rõ trong comment Task + gắn nhãn `blocked-external` + báo trưởng nhóm.

## 6. BẪY DỄ GẶP
| Bẫy | Hậu quả | Cách tránh |
