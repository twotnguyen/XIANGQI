## 1. MỤC TIÊU (đọc trong 1 phút)

Tạo **bộ khung kho mã** cho cả dự án: một thư mục gốc chứa 6 "gói" (package) — 3 ứng dụng và 3 thư viện dùng chung — cài bằng **một lệnh**, build bằng **một lệnh**, chạy thử bằng **một lệnh**. Chưa có chức năng nào; chỉ cần:
- Web hiện chữ **"Cờ Tướng Online"**.
- Server trả `{"ok":true}` ở `GET /health`.
- Các lệnh kiểm thử **chưa có công cụ** phải báo lỗi rõ ràng (không được "xanh giả").

Đây là Task **đầu tiên** của dự án — mọi người khác đều chờ Task này.

## 2. KHÁI NIỆM CẦN BIẾT

| Khái niệm | Giải thích |
|---|---|
| **Monorepo** | Một kho Git chứa nhiều dự án con. Ở đây: web, server, ai-worker và 3 thư viện dùng chung nằm cùng một kho để **dùng chung code luật cờ** giữa giao diện và máy chủ |
| **pnpm workspace** | Tính năng của pnpm cho monorepo: `pnpm install` ở thư mục gốc cài cho mọi package; package này import package kia bằng tên `@xiangqi/...` như thư viện bình thường |
| **Package** | Một thư mục có `package.json` riêng. Ví dụ `packages/game-rules` tên `@xiangqi/game-rules` |
| **TypeScript strict** | Chế độ kiểm kiểu nghiêm ngặt: bắt lỗi `undefined`, thiếu kiểu, biến không dùng… ngay lúc biên dịch thay vì lúc chạy |
| **Khoá chính xác phiên bản** | Ghi `"react": "19.1.0"` thay vì `"^19.1.0"`. Dấu `^` cho phép tự lên bản mới ⇒ hai người cài ra hai bản khác nhau ⇒ "máy tôi chạy được" |
| **`pnpm-lock.yaml`** | File ghi chính xác mọi phiên bản đã cài. `pnpm install --frozen-lockfile` = cài **đúng** như file này, không tự sửa |
| **Script `NOT_IMPLEMENTED`** | Lệnh như `pnpm test:e2e` sẽ có ở Task sau. Hiện tại nó phải **thoát lỗi** và in tên Task sẽ làm, để không ai tưởng test đã chạy xanh |

### 5.2 File gốc

**`.gitignore`**
```
node_modules
dist
.env
artifacts
test-results
playwright-report
coverage
.DS_Store
```

**`.npmrc`**
```
save-exact=true
```

**`pnpm-workspace.yaml`**
```yaml
packages:
  - 'apps/*'
  - 'packages/*'
```

**`tsconfig.base.json`** — bật **tối thiểu** các cờ sau:
```jsonc
{
  "compilerOptions": {
    "target": "ES2022", "module": "NodeNext", "moduleResolution": "NodeNext",
    "strict": true,
    "noUncheckedIndexedAccess": true,      // arr[i] có thể undefined ⇒ bắt kiểm
    "noImplicitOverride": true,
    "exactOptionalPropertyTypes": true,
    "noUnusedLocals": true, "noUnusedParameters": true,
    "isolatedModules": true,
    "declaration": true, "sourceMap": true, "skipLibCheck": true
  }
}
```
(Web dùng `"module": "ESNext"`, `"moduleResolution": "Bundler"`, `"jsx": "react-jsx"` trong `apps/web/tsconfig.json` — ghi đè riêng.)

### 5.3 Sáu package

| Thư mục | Tên package | Nội dung ban đầu |
|---|---|---|
| `apps/web` | `@xiangqi/web` | React + Vite + React Router. `index.html`, `src/main.tsx` hiển thị `<h1>Cờ Tướng Online</h1>`. Script `dev` = `vite --port 5173 --strictPort`, `build` = `tsc -b && vite build` |
| `apps/server` | `@xiangqi/server` | NestJS. `GET /health` trả `{ "ok": true }` (Content-Type JSON). Cổng lấy từ biến `PORT`, mặc định **3000**. Script `dev` = `nest start --watch`, `start` = `node dist/main.js` |
| `apps/ai-worker` | `@xiangqi/ai-worker` | `src/main.ts` in `ai-worker ready` rồi thoát; chưa có logic |
| `packages/contracts` | `@xiangqi/contracts` | `src/index.ts` có `export {};` |
| `packages/game-rules` | `@xiangqi/game-rules` | `src/index.ts` có `export {};` |
| `packages/ai` | `@xiangqi/ai` | `src/index.ts` có `export {};` |

Mỗi package có `package.json`, `tsconfig.json` (kế thừa `../../tsconfig.base.json`, bật `"composite": true`, `outDir: "dist"`) và script `build`, `typecheck`.

Tạo nhanh web và server bằng công cụ chính thức rồi dọn bớt:
```bash
pnpm create vite apps/web --template react-ts
pnpm dlx @nestjs/cli new apps/server --package-manager pnpm --skip-git
```
Sau đó xoá file mẫu không dùng, đổi tên package, bỏ mọi `^`/`~` trong `package.json`.

### B. Các ca kiểm thử

#### QA01.1.1-01 · Cài đặt đúng lockfile
- **Các bước:** `pnpm install --frozen-lockfile; echo "exit=$?"` rồi `git status`.
- **Mong đợi:** `exit=0`; `git status` báo sạch (`pnpm-lock.yaml` **không** bị sửa).

#### QA01.1.1-02 · Build và kiểm kiểu cả 6 package
- **Các bước:** `pnpm build; echo "exit=$?"` → `pnpm typecheck; echo "exit=$?"` → `ls -d apps/*/dist packages/*/dist`.
- **Mong đợi:** cả hai `exit=0`; lệnh `ls` in đúng **6** thư mục `dist`.

#### QA01.1.1-03 · Chạy dev: web và server cùng lúc ⭐
- **Các bước:** `pnpm dev`; mở trình duyệt http://localhost:5173; mở terminal khác chạy `curl -i http://127.0.0.1:3000/health`.
- **Mong đợi:** trình duyệt hiện chữ **Cờ Tướng Online**; `curl` in:
  ```text
  HTTP/1.1 200 OK
  Content-Type: application/json; charset=utf-8
  …
  {"ok":true}
  ```
- **Bằng chứng:** ảnh trình duyệt + terminal.

#### QA01.1.1-04 · Lane chưa có công cụ không "xanh giả" ⭐
- **Các bước:** chạy lần lượt, mỗi lệnh kèm `; echo "exit=$?"`: `pnpm lint`, `pnpm test:unit`, `pnpm test:e2e`, `pnpm test:integration`, `pnpm test:ai`, `pnpm test:media`, `pnpm test:load`.
- **Mong đợi:** cả 7 lệnh in `NOT_IMPLEMENTED — xem TKxx.y.z` (đúng Task ở bảng 5.4) và `exit=1`.

#### QA01.1.1-05 · Khoá chính xác phiên bản
- **Các bước:** `grep -rnE '"[\^~][0-9]' --include=package.json apps packages package.json` → `cat .npmrc` → `grep -n '"engines"\|"packageManager"' package.json`.
- **Mong đợi:** lệnh grep đầu **không in gì**; `.npmrc` có `save-exact=true`; `package.json` có `engines.node` và `packageManager` với số cụ thể (không có `x` hay `^`).

#### QA01.1.1-06 · TypeScript strict thật sự bật
- **Các bước:** mở `tsconfig.base.json` → thêm tạm vào `packages/game-rules/src/index.ts` dòng `export const a: number[] = []; export const b: number = a[0];` → `pnpm typecheck` → hoàn lại (`git checkout packages/game-rules/src/index.ts`).
- **Mong đợi:** file có `"strict": true` và `"noUncheckedIndexedAccess": true`; `pnpm typecheck` **báo lỗi** ở dòng tạm (`number | undefined` không gán được cho `number`).

#### QA01.1.1-07 · README và file mẫu
- **Các bước:** đọc `README.md`, `.env.example`, `.gitignore`, `docs/test-reports/toolchain.md`.
- **Mong đợi:** README có 5 mục ở 5.5 và lệnh chạy được như ghi; `.env.example` chỉ có giá trị mẫu; `.gitignore` có `.env`, `node_modules`, `dist`; `toolchain.md` có phiên bản thật (so với `node -v`, `pnpm -v`).

#### QA01.1.1-08 · Không phá đặc tả cũ
- **Các bước:** `git log --oneline -3 -- docs/ | cat` và `ls docs Jira`.
- **Mong đợi:** thư mục `docs/`, `Jira/` còn nguyên; lịch sử commit cũ còn.
