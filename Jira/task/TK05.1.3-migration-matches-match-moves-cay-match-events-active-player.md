**Việc cần làm:**
1. `<ts>_matches.sql`:
   - **`matches`**: `id`, `room_id` (**nullable** — ván với máy không có phòng), `mode`, `status`, `red_user_id`, `black_user_id`, `ai_side`, `ai_level`, `time_control`, `red_ms`, `black_ms`, `running_since`, `version bigint`, `ply int`, `outcome_winner`, `outcome_reason`, `started_at`, `ended_at`.
     ```sql
     CHECK (mode IN ('ONLINE','AI'))
     CHECK (status IN ('ACTIVE','FINISHED','INTERRUPTED'))
     CHECK (version >= 0 AND ply >= 0)
     CHECK (outcome_reason IS NULL OR outcome_reason IN ('CHECKMATE','STALEMATE','REPETITION','AGREED_DRAW',
       'RESIGN','TIMEOUT','INACTIVITY','DISCONNECT','BOTH_OFFLINE','SERVER_RESTART','AI_UNAVAILABLE'))
     CHECK ((mode='ONLINE' AND room_id IS NOT NULL) OR (mode='AI' AND room_id IS NULL))
     ```
   - **`match_moves` — CÂY**: `id uuid PK` (= moveId), `match_id FK`, `parent_move_id uuid NULL FK match_moves(id)` (NULL = nước đầu), `side`, `from_x`, `from_y`, `to_x`, `to_y` (CHECK 0..8 / 0..9), `created_at`. ⛔ **Không** có `UNIQUE (match_id, ply)` — sau đi lại nhiều nước chung một cha là **bắt buộc**.
   - **`match_events`**: `id`, `match_id`, `version`, `type`, `payload jsonb`, `created_at`; `UNIQUE (match_id, version)`; `CHECK (type IN ('START','MOVE','UNDO','PROPOSAL_CREATED','PROPOSAL_RESOLVED','RESULT'))`.
   - **`active_players`**: `user_id PK`, `match_id` — một người một ván đang chạy.
   - Cuối file: `ALTER TABLE rooms ADD CONSTRAINT ... FOREIGN KEY (current_match_id) REFERENCES matches(id)`.
   - Index `match_moves(match_id, parent_move_id)`, `match_events(match_id, version)`.
2. `<ts>_commands.sql`:
   - **`command_receipts`**: PK `(match_id, actor_id, command_id)`, `command_type` CHECK IN ('MOVE','RESIGN','PROPOSE','RESPOND','UNDO_AI','CONFIRM_ALIVE'), `payload_hash text NOT NULL` (**hash gồm cả `command_type`** + payload chuẩn hoá), `applied_version`, `result jsonb`, `created_at`.
   - **`match_proposals`**: `id`, `match_id`, `kind` CHECK DRAW/UNDO, `requester_id`, `base_ply`, `created_version`, `expires_at`, `status` CHECK PENDING/ACCEPTED/REJECTED/EXPIRED/WITHDRAWN; `CREATE UNIQUE INDEX ON match_proposals(match_id) WHERE status='PENDING'`.
   - **`room_rematch_votes`**: PK `(room_id, match_id, user_id)`, `accepted`, `created_at`.
   - **`room_command_receipts`**: PK `(room_id, actor_id, command_id)`, `command_type` CHECK IN ('READY','CONFIG','SIDE_SWAP_REQUEST','SIDE_SWAP_RESPOND','SIDE_SWAP_CANCEL','REMATCH'), `payload_hash`, `result jsonb`, `room_version`, `created_at` — giữ tới khi phòng CLOSED.
   - **`room_side_swap_proposals`**: `id`, `room_id FK`, `requester_membership_id`, `responder_membership_id`, `config_revision`, `expires_at NOT NULL`, `status` CHECK PENDING/ACCEPTED/REJECTED/CANCELLED/EXPIRED, `created_at`; `UNIQUE INDEX (room_id) WHERE status='PENDING'`; `CHECK (requester_membership_id <> responder_membership_id)`; không cascade xoá khi thành viên rời.
3. Hàm tiện ích TS (dùng ở EP10) `payloadHash(commandType, payload)` = SHA-256 của JSON chuẩn hoá `{type, payload}` với khoá sắp xếp — đặt ở `apps/server/src/db/payload-hash.ts` + unit test `RESIGN {}` ≠ `UNDO_AI {}`.
4. Test `tests/integration/issue-038.test.ts`, `issue-039.test.ts`.

**Bẫy dễ gặp:** lần trước "đi nước mới sau khi đi lại luôn lỗi trùng khoá → 500" vì lưu danh sách có UNIQUE ply (`F-01`). Hash không gồm `command_type` ⇒ gửi RESIGN rồi UNDO_AI cùng commandId sẽ nhận lại kết quả đầu hàng.
