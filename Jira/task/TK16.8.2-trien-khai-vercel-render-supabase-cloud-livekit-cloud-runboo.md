## 2. KHÁI NIỆM CẦN BIẾT

| Khái niệm | Giải thích |
|---|---|
| **Rewrite về `index.html`** | Ứng dụng một trang: mọi đường dẫn (`/lobby`) phải trả `index.html`, nếu không F5 bị 404 |
| **DEMO_SLEEP_ALLOWED** | Gói miễn phí Render **ngủ** khi không dùng. Được phép — **không** dùng ping chống ngủ. Thức dậy ⇒ ván cũ INTERRUPTED |
| **`VITE_*` là công khai** | Mọi biến `VITE_*` bị đóng vào gói JS gửi cho trình duyệt ⇒ **tuyệt đối** không đặt khoá bí mật |
| **`supabase db push`** | Áp migration `.sql` lên Supabase Cloud — **không** `prisma migrate` |

**Từ kỹ thuật cần tra:** [Migration](../05-TU-DIEN-KY-THUAT.md#migration) · [Pipeline CI](../05-TU-DIEN-KY-THUAT.md#pipeline) · [Token](../05-TU-DIEN-KY-THUAT.md#jwt)

## 4. PHẠM VI
**✅ Làm:** `render.yaml`, `vercel.json` (rewrite + headers bảo mật), `.env.example` đầy đủ, cấu hình dashboard, `docs/runbook.md`.

## 5. HƯỚNG DẪN LÀM TỪNG BƯỚC
1. **Vercel**: build `apps/web`; rewrite mọi đường dẫn về `index.html`; headers bảo mật (CSP, `frame-ancestors`, `nosniff`, `Referrer-Policy`).
2. **Render**: 1 Web Service chạy server (AI child do server spawn, ≤ 2 worker); health check `/healthz`; không ping chống ngủ.
3. **Supabase Cloud**: `supabase db push`; bật xác minh email; SMTP riêng (nếu có); redirect URLs = Vercel `/auth/callback`; Google provider + thêm redirect `https://<ref>.supabase.co/auth/v1/callback` vào OAuth client.
4. **Server env**: `APP_ORIGIN` = đúng địa chỉ Vercel; `DATABASE_URL` role `app_server`; khoá LiveKit Cloud; `INVITE_HMAC_KEY` mới (khác local).
5. Giá trị thật **chỉ** điền trên dashboard; **không commit**; khoá bí mật **không** mang tiền tố `VITE_`.
6. `bootId` mỗi lần khởi động; kiểm ngủ/thức: ván cũ INTERRUPTED; UI báo kết nối lại.
7. **`docs/runbook.md`**: xem log (Render/Vercel/Supabase) · khởi động lại · rollback (Render rollback deploy, Vercel promote bản cũ) · chạy migration · xoay khoá · 5 sự cố (CORS sai origin, redirect OAuth sai, LiveKit token lỗi, AI child không READY, DB hết kết nối) + cách xử lý.
8. Thiếu tài khoản dịch vụ ⇒ ghi rõ, nhãn `blocked-external`, làm phần còn lại.

## 6. BẪY DỄ GẶP
