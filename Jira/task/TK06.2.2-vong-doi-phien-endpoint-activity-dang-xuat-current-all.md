**Việc cần làm:**
1. `app-session.service.ts` — dùng **đồng hồ tiêm vào** (`Clock` provider):
   ```ts
   function nextIdle(mode, now, oldIdle, absolute) {
     if (now >= oldIdle || (absolute !== null && now >= absolute)) throw EXPIRED;
     const windowMs = mode === 'REMEMBERED' ? 30*86400000 : 30*60000;
     return Math.min(absolute ?? Infinity, Math.max(oldIdle, now + windowMs));
   }
   ```
   Gia hạn trong transaction `SELECT ... FOR UPDATE` hàng app_session → kiểm hạn/thu hồi → UPDATE `last_active_at`, `idle_expires_at` (chỉ tăng). Hai activity đồng thời không rút ngắn hạn.
2. `POST /api/v1/auth/activity` body `{ kind: 'PAGE_VIEW' | 'NAVIGATION' }` — client gọi khi người dùng mở trang/chuyển màn. Lệnh nghiệp vụ (đi cờ, chat…) gọi `appSession.touch()` bên trong service tương ứng (các Epic sau). **Không** gia hạn khi: refresh token, heartbeat, polling, nhận sự kiện, reconnect.
3. `logout.controller.ts` — `POST /api/v1/auth/logout` body `{ scope: 'CURRENT' | 'ALL', operationId }`:
   ```
   ① Transaction: đặt revoked_at cho app_sessions trong phạm vi (CURRENT: đúng auth_session_id; ALL: mọi phiên user)
      + INSERT auth_security_jobs (reason LOGOUT, scope, target_auth_session_ids = snapshot, revocation_cutoff = now)
   ② Ngoài transaction: gọi Auth Admin signOut (scope local/global); lỗi ⇒ giữ fence, job retry
   ③ Trả { status: 'COMPLETED' | 'PENDING' }; chưa xác nhận Auth ⇒ PENDING, UI hiện "Đã chặn phiên, đang hoàn tất đăng xuất" + Thử lại cùng operationId
   ```
   Cùng `operationId` + cùng payload ⇒ trả trạng thái cũ; payload khác ⇒ 409 `CONFLICT`.
4. Worker `revoked-sessions.service.ts` chạy định kỳ (hẹn giờ trong tiến trình): lấy job PENDING/RUNNING hết lease, gọi lại Auth, tăng attempts; khởi động lại server vẫn tiếp tục. Ghi chú: ngắt socket (EP10) và media (EP14) sẽ đăng ký vào job này sau.
5. Không xoá tombstone phiên khi job còn PENDING.
6. Test `tests/integration/issue-050.test.ts`, `issue-051.test.ts` với đồng hồ giả: biên `idle−1ms / idle / idle+1ms`, `absolute−1ms / absolute / absolute+1ms`.

**Bẫy dễ gặp:** đổi `now < deadline` thành `now <= deadline`; để refresh token dời hạn; báo đăng xuất xong khi Auth chưa xác nhận.
