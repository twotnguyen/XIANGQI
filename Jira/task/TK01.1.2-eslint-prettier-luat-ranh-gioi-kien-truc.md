**Mục tiêu:** Kiểm tra mã tự động cho cả kho, **có luật chặn import sai ranh giới** giữa các package.

**Việc cần làm:**
1. Cài ESLint 9 (cấu hình phẳng `eslint.config.js`), `typescript-eslint`, `eslint-config-prettier`, `eslint-plugin-react-hooks`.
2. Bật ở mức **error**: `@typescript-eslint/no-floating-promises`, `no-misused-promises`, `await-thenable`, `no-explicit-any`, `consistent-type-imports`.
3. Luật ranh giới bằng `no-restricted-imports` theo đường dẫn file:
   | File thuộc | Chỉ được import | Cấm (ví dụ) |
   |---|---|---|
   | `packages/contracts/**` | thư viện `zod` | mọi package nội bộ `@xiangqi/*` |
   | `packages/game-rules/**` | `@xiangqi/contracts` | `pg`, `@prisma/*`, `@nestjs/*`, `fs`, `http`, `react`, `@xiangqi/ai` |
   | `packages/ai/**` | `@xiangqi/contracts`, `@xiangqi/game-rules` | `pg`, `@nestjs/*`, `react`, `fs`, `http` |
   | `apps/web/**` | `@xiangqi/contracts`, `@xiangqi/game-rules` | `@xiangqi/ai`, `pg`, `@nestjs/*`, `@prisma/*` |
4. Prettier `.prettierrc`: 2 dấu cách, nháy đơn, dấu phẩy cuối `all`, độ rộng 100. `.prettierignore` bỏ `dist`, `docs`, `coverage`.
5. Script gốc `lint` = `eslint . --max-warnings 0` (cảnh báo cũng làm exit ≠ 0). Script `format` = `prettier --write .`.
6. Viết `tests/bootstrap/lint-probes.mjs` (Node thuần, không cần Vitest): tạo tạm file `packages/game-rules/src/__lint_probe.ts` với từng nội dung vi phạm, chạy ESLint CLI, assert exit ≠ 0 và thông báo đúng tên luật, rồi **xoá file trong `finally`**. Ba probe:
   - `import type { Pool } from 'pg'; export type P = Pool;` → phải báo `no-restricted-imports`
   - `export const bad: any = 1;` → phải báo `no-explicit-any`
   - `async function t(): Promise<void> {} t();` → phải báo `no-floating-promises`

**File/module:** `eslint.config.js`, `.prettierrc`, `.prettierignore`, `tests/bootstrap/lint-probes.mjs`, `package.json` gốc.

**Không làm:** sửa code chức năng (chưa có).

**Bẫy dễ gặp:** luật ranh giới viết sai glob sẽ không bao giờ kích hoạt mà lint vẫn xanh — chỉ có probe mới chứng minh được. Probe `pg` phải báo đúng `no-restricted-imports`, không phải lỗi "module not found".

**Bàn giao:** `pnpm lint` thật; `node tests/bootstrap/lint-probes.mjs` exit 0 khi cả 3 probe bị bắt.

**Tự kiểm:** `pnpm lint` exit 0 trên kho sạch; chạy script probe; `git status` sạch sau probe (file tạm đã xoá).
