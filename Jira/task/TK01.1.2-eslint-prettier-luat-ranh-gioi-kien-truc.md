## 1. MỤC TIÊU (đọc trong 1 phút)

Bật **ESLint** (công cụ soát lỗi code) và **Prettier** (công cụ định dạng code) cho cả kho, kèm **luật ranh giới kiến trúc**: gói luật cờ không được gọi DB, giao diện không được import máy cờ AI… Vi phạm ⇒ `pnpm lint` báo lỗi và CI chặn merge.

Và phải **chứng minh** luật hoạt động bằng 3 "đầu dò" (probe): cố tình viết code sai, lint phải bắt được.

## 2. KHÁI NIỆM CẦN BIẾT

| Khái niệm | Giải thích |
|---|---|
| **ESLint** | Đọc code và báo lỗi theo luật. Ví dụ luật `no-floating-promises`: gọi hàm `async` mà quên `await` ⇒ lỗi (lỗi này làm lệnh chạy ngầm, lỗi xảy ra không ai biết) |
| **Prettier** | Tự định dạng code (thụt lề, dấu nháy…) để cả nhóm viết giống nhau, review PR không bị nhiễu vì khác định dạng |
| **Luật ranh giới** (`no-restricted-imports`) | Cấm một thư mục import một số thư viện. Ví dụ `packages/game-rules` là **luật cờ thuần** — chạy được cả trong trình duyệt — nên **cấm** import `pg` (thư viện DB) |
| **Probe (đầu dò)** | Script tạm tạo một file vi phạm, chạy lint, **mong lint thất bại**. Nếu lint vẫn xanh ⇒ luật viết sai (glob sai thư mục) |
| `--max-warnings 0` | Cảnh báo (warning) cũng tính là lỗi ⇒ không ai để cảnh báo tồn đọng |

**Vì sao cần ranh giới?** Kiến trúc dự án (`ARCH` §9): *luật cờ* không biết mạng/DB/người dùng; *AI* không biết mạng/DB/phòng; *giao diện* không chạy AI. Để ranh giới bằng lời hứa thì sớm muộn sẽ có người import nhầm — lint chặn tự động.

### 5.1 Cài thư viện (khoá chính xác phiên bản — `.npmrc` đã có `save-exact`)
```bash
pnpm add -Dw eslint @eslint/js typescript-eslint eslint-config-prettier eslint-plugin-react-hooks prettier globals
```

### 5.2 `eslint.config.js` (cấu hình phẳng của ESLint 9)

Bật mức **error** các luật:

| Luật | Bắt lỗi gì |
|---|---|
| `@typescript-eslint/no-floating-promises` | Gọi hàm async không `await`/không xử lý |
| `@typescript-eslint/no-misused-promises` | Truyền hàm async vào chỗ không chờ Promise (ví dụ `onClick`) sai cách |
| `@typescript-eslint/await-thenable` | `await` một thứ không phải Promise |
| `@typescript-eslint/no-explicit-any` | Dùng kiểu `any` (tắt kiểm kiểu) |
| `@typescript-eslint/consistent-type-imports` | Import kiểu phải dùng `import type` |
| `react-hooks/rules-of-hooks`, `react-hooks/exhaustive-deps` | Dùng hook React sai (chỉ cho `apps/web`) |

Luật ranh giới theo thư mục:

| File thuộc | Chỉ được import (nội bộ) | Cấm (ví dụ) |
|---|---|---|
| `packages/contracts/**` | thư viện `zod` | mọi `@xiangqi/*` |
| `packages/game-rules/**` | `@xiangqi/contracts` | `pg`, `@prisma/*`, `@nestjs/*`, `fs`, `node:fs`, `http`, `node:http`, `react`, `@xiangqi/ai` |
| `packages/ai/**` | `@xiangqi/contracts`, `@xiangqi/game-rules` | `pg`, `@prisma/*`, `@nestjs/*`, `react`, `fs`, `http` |
| `apps/web/**` | `@xiangqi/contracts`, `@xiangqi/game-rules` | `@xiangqi/ai`, `pg`, `@nestjs/*`, `@prisma/*` |

Mẫu một khối (làm tương tự cho các thư mục khác):
```js
{
  files: ['packages/game-rules/**/*.ts'],
  rules: {
    'no-restricted-imports': ['error', {
      paths: ['pg', 'fs', 'node:fs', 'http', 'node:http', 'react', '@xiangqi/ai'].map((name) => ({ name, message: 'game-rules là luật cờ thuần — không được phụ thuộc DB/mạng/giao diện/AI' })),
      patterns: [{ group: ['@prisma/*', '@nestjs/*'], message: 'game-rules không được phụ thuộc framework máy chủ' }],
    }],
  },
}
```
Bỏ qua: `dist`, `coverage`, `node_modules`, `docs`, `Jira`, `playwright-report`, `test-results`.

### 5.5 Đầu dò `tests/bootstrap/lint-probes.mjs` (Node thuần)
```js
import { writeFileSync, rmSync } from 'node:fs';
import { spawnSync } from 'node:child_process';
const FILE = 'packages/game-rules/src/__lint_probe.ts';
const probes = [
  { code: "import type { Pool } from 'pg';\nexport type P = Pool;\n", rule: 'no-restricted-imports' },
  { code: 'export const bad: any = 1;\n', rule: 'no-explicit-any' },
  { code: 'async function t(): Promise<void> {}\nt();\nexport {};\n', rule: 'no-floating-promises' },
];
let failed = 0;
for (const p of probes) {
  try {
    writeFileSync(FILE, p.code);
    const r = spawnSync('pnpm', ['exec', 'eslint', FILE], { encoding: 'utf8' });
    const ok = r.status !== 0 && (r.stdout + r.stderr).includes(p.rule);
    console.log(`${ok ? '✓' : '✗'} probe ${p.rule}: exit=${r.status}`);
    if (!ok) failed++;
  } finally { rmSync(FILE, { force: true }); }   // luôn xoá file tạm, kể cả khi lỗi
}
process.exit(failed ? 1 : 0);
```
Script `lint:probes` = `node tests/bootstrap/lint-probes.mjs`.

## 6. BẪY DỄ GẶP

| Bẫy | Hậu quả | Cách tránh |
|---|---|---|
| Glob sai (ví dụ `packages/game-rule/**`) | Luật không bao giờ chạy, lint vẫn xanh | Chạy probe — chỉ probe mới chứng minh |
| Probe `pg` bị báo lỗi "module not found" thay vì `no-restricted-imports` | Probe "đỏ" nhưng sai lý do | Dùng `import type` và kiểm đúng **tên luật** trong output |
| Quên xoá file probe khi script lỗi | File rác vào commit | `try … finally` |
| Tắt luật cho nhanh (`eslint-disable`) | Lỗi thật lọt | Không dùng `eslint-disable` trừ khi có lý do ghi rõ trong comment và reviewer đồng ý |
