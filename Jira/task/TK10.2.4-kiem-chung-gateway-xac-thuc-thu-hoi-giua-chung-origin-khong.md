## 1. MỤC TIÊU

Tester kiểm **sâu** máy chủ realtime như kẻ gian: kết nối không token / token giả / Origin lạ; **đăng xuất giữa chừng** rồi vẫn cố gửi sự kiện; **nghe lén phòng khác** bằng cách tự đặt tên room socket.

**Từ kỹ thuật cần tra:** [Socket.IO](../05-TU-DIEN-KY-THUAT.md#socket) · [Token](../05-TU-DIEN-KY-THUAT.md#jwt) · [IDOR](../05-TU-DIEN-KY-THUAT.md#idor) · [Đồng hồ tiêm vào](../05-TU-DIEN-KY-THUAT.md#clock)

## 2. ĐIỀU KIỆN BẮT ĐẦU
- [ ] TK10.2.1, TK06.2.2 ở **Ready For Test** trở lên.
- [ ] Đã cài `qa`, `qsock` ([Sổ tay §5](../04-HUONG-DAN-KIEM-THU.md)).

## 3. MÔI TRƯỜNG VÀ DỮ LIỆU
1. `git pull && pnpm db:reset && pnpm dev`. `qa login A; qa login B; qa login C`.
2. Phòng P1 của A (B đã vào): `qa room-create A PUBLIC 0 P1; P1=$(qa get ROOM); qa grant A B PLAY; qa join B PLAY inv`.
3. Lệnh đăng xuất cho token đã lưu: `out() { curl -s -X POST http://127.0.0.1:3000/api/v1/auth/logout -H "Authorization: Bearer $(qa get token_$1)" -H 'Content-Type: application/json' -d "{\"scope\":\"$2\",\"operationId\":\"$(qa cid)\"}"; }`.
