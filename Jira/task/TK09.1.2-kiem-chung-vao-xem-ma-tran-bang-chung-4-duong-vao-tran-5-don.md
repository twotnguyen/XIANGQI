## 1. MỤC TIÊU

Tester kiểm **độc lập, sâu** luồng vào xem — gọi thẳng máy chủ bằng `qa` (HTTP) và `qsock` (socket), **giả mạo** như kẻ gian:
1. **Ma trận bằng chứng**: phòng không tồn tại / riêng tư / đóng ⇒ phản hồi **giống hệt**; mã phòng khác **không** mở được phòng riêng (**F-03**).
2. **LOCKED**: không ai xem được bằng bất kỳ đường nào; mời **chơi** vẫn được.
3. **Chưa xác minh email**: bị chặn ở **16 biến thể** (4 đường × PLAY/WATCH × HTTP/socket).
4. **Trần 5 người xem** khi tranh cùng lúc; **giữ ghế 15 giây**.

**Từ kỹ thuật cần tra:** [IDOR](../05-TU-DIEN-KY-THUAT.md#idor) · [Socket.IO](../05-TU-DIEN-KY-THUAT.md#socket) · [Race](../05-TU-DIEN-KY-THUAT.md#race) · [Đồng hồ tiêm vào](../05-TU-DIEN-KY-THUAT.md#clock)

## 3. MÔI TRƯỜNG VÀ DỮ LIỆU
1. `git pull && pnpm db:reset && pnpm dev`. Tài khoản **A, B, C, N, S1–S6**. `qa login-all; for u in N S4 S5 S6; do qa login $u; done`.
2. Bạn bè A–S1, A–S2 (cho lời mời trực tiếp): `qa friend-add A S1 && qa friend-respond S1 yes; qa friend-add A S2 && qa friend-respond S2 yes`.
3. Lệnh giúp: `dem() { qa sql "select role, count(*) from room_members where room_id='$(qa get ROOM)' group by role"; }` · `ra() { local u; u=$(qa uid $1); qa sql "delete from room_members where user_id='$u'; delete from user_active_room where user_id='$u'"; }`.
4. **Tài khoản chưa xác minh (U)**: tạo tài khoản `tester_u` đã xác minh (Sổ tay §3) → `qa login tester_u` (lấy token khi còn xác minh) → **gỡ xác minh**: `qa sql "update auth.users set email_confirmed_at = null where id='$(qa uid tester_u)'"`. Từ giờ mọi lệnh của `tester_u` đều là "tài khoản chưa xác minh".
