**Việc cần làm:** `apps/server/src/modules/rooms/lobby.service.ts` (Prisma đọc)
1. `GET /api/v1/rooms?cursor=` — 20/trang, `ORDER BY created_at DESC, id DESC`, cursor = `(created_at, id)` mã hoá base64 (không OFFSET).
2. Điều kiện **liệt kê tường minh**: `visibility = 'PUBLIC' AND status IN ('WAITING','PLAYING')` (⛔ không dùng `status <> 'CLOSED'` vì sẽ lọt FINISHED).
3. Mỗi phòng: `{ id, name, ownerDisplayName, timeControl, status, spectatorCount, playerCount }` — **không** thế cờ/nước đi.
4. Socket: client gửi `lobby.subscribe` ⇒ vào room socket `lobby`; phát `lobby.roomUpserted` / `lobby.roomRemoved` khi: tạo phòng PUBLIC, đóng phòng, đổi chế độ (vào/ra PUBLIC), đổi số người xem/người chơi, ván bắt đầu (WAITING→PLAYING), ván kết thúc (→ FINISHED ⇒ **removed**), tái đấu (→ PLAYING ⇒ **upserted**). Nối `lobbyPublisher` của TK08.1.1 vào đây.
5. `EXPLAIN` truy vấn dùng partial index sảnh.
6. Test `tests/integration/issue-062.test.ts` (socket.io-client thật).
